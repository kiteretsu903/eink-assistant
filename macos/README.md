# macOS source

The Swift source for the macOS edition lives in `Sources/`.

From the repository root, the existing commands remain available:

```bash
./build.sh
./package-dmg.sh
```

Shared localization and product artwork remain in the repository-level
`Resources/` directory so the macOS and Windows editions use the same strings
and branding assets. Product documentation and release information remain in
the repository root and `docs/` website.
