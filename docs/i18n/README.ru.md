**Настройка чёрно-белых и цветных дисплеев с электронными чернилами в macOS и Windows.**

[Сайт продукта](https://kiteretsu903.github.io/eink-assistant/ru/)

E-Ink Assistant настраивает контрастность текста, детали в тенях и цвет на выбранных вами дисплеях с электронными чернилами. Другие дисплеи остаются без изменений. Версия для macOS работает в строке меню; версия для Windows — в области уведомлений.

[Скачать macOS 2.6](https://github.com/kiteretsu903/eink-assistant/releases/download/macos-v2.6-windows-v1.2/E-Ink-Assistant-v2.6.dmg) ·
[Скачать Windows 1.2](https://github.com/kiteretsu903/eink-assistant/releases/download/macos-v2.6-windows-v1.2/E-Ink-Assistant-Windows-1.2-Setup.exe) ·
[Все выпуски](https://github.com/kiteretsu903/eink-assistant/releases)

Бесплатное приложение с открытым исходным кодом под лицензией MIT.

## Настройки

| Настройка | Для чего | Что делает |
|---|---|---|
| Контрастность текста | Чтение | Затемняет бледный текст на среднем, сильном, резком и предельном уровнях. Более сильные уровни делают края жёстче ценой потери серых деталей. |
| Улучшение видео | Фото и видео | Раскрывает детали в тенях на слабом, среднем и сильном уровнях. Отключайте для чтения, поскольку эта функция также осветляет тёмный текст. |
| Насыщенность и RGB | Цветные электронные чернила | Предоставляет шесть предустановок насыщенности, ползунок насыщенности 0%–300% и коррекцию RGB 0%–200%, если платформа поддерживает эти функции. |
| Уменьшение мерцания | Поддерживаемые дисплеи macOS | Устраняет видимое мерцание от дизеринга и автоматически включается для дисплеев, отмеченных как использующие электронные чернила. |
| Night Shift и True Tone | Дисплеи, на которые влияют изменения цветовой температуры | Исключает выбранный дисплей macOS из действия этих функций. Требуется разрешение администратора и переподключение дисплея; настройка сохраняется после выхода. |
| Уменьшение прозрачности и движения | Панели с медленным обновлением | Упрощает системные визуальные эффекты. В macOS используется помощник, установку которого пользователь подтверждает один раз. |
| Расширенные кривые | Точная настройка конкретной панели | Позволяет настроить точку перегиба, гамму, точку чёрного и точку белого с интерактивным графиком и пятью именованными предустановками. |

## Установка

### macOS 14+, Apple silicon

1. Скачайте DMG для macOS 2.6 по ссылке выше.
2. Откройте его и перетащите **E-Ink Assistant** в папку **Программы**.
3. Попробуйте открыть приложение один раз. Если macOS заблокирует его, откройте **Системные настройки → Конфиденциальность и безопасность** и выберите **Всё равно открыть**.

Это независимо разработанное приложение, которое пока отсутствует в App Store. При первом запуске macOS покажет предупреждение о невозможности проверки. Исходный код полностью открыт: вы можете изучить его, прежде чем решать, использовать ли приложение.

Если кнопка **Всё равно открыть** не появляется после перемещения приложения в папку «Программы», откройте Терминал и выполните:

```
xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"
```

### От Windows 7 SP1 до Windows 11, x64

1. Скачайте установщик Windows 1.2 по ссылке выше.
2. Запустите Setup и подтвердите запрос прав администратора.
3. Откройте E-Ink Assistant из меню «Пуск» или области уведомлений.

Точную доступность функций в зависимости от версии Windows, видеокарты, драйвера и подключения дисплея см. в [WINDOWS.md](../../WINDOWS.md).

## Использование

<p align="center">
  <img src="../../docs/en/app-displays-v2-1.png" alt="Выбор дисплеев в E-Ink Assistant v2.1" width="440">
</p>

1. Откройте приложение из строки меню macOS или области уведомлений Windows.
2. Отметьте каждый чёрно-белый или цветной дисплей с электронными чернилами, который хотите настроить.
3. Сначала установите сбалансированную аппаратную контрастность в меню самого монитора.
4. Выберите контрастность текста для чтения или улучшение видео для мультимедиа; не используйте их одновременно.
5. На цветных электронных чернилах настройте насыщенность и RGB, если платформа их поддерживает.

**При выходе исходные настройки дисплеев восстанавливаются**, а при запуске ваши настройки применяются снова. Включите **Запускать при входе в систему** для автоматического запуска.

## Настройка дисплея

Перед настройкой приложения установите сбалансированную контрастность в меню самого монитора. Встроенные предустановки подобраны визуально на **Bigme B251 Pro** (R2 FW V2.0) с параметрами **Web Mode, аппаратная Gamma — уровень 3, контрастность — 50, Color Restore Mode — off**. Для чёрно-белой панели или другой цветной модели понадобятся свои значения. Расширенный режим даёт доступ ко всей кривой, а настройки сохраняются отдельно для каждого дисплея.

Уменьшение мерцания доступно только на Apple Silicon и скрывается там, где не поддерживается.

<details>
<summary>Помощник уменьшения прозрачности и движения в macOS</summary>

При первом использовании нужно подтвердить **Добавить быструю команду** в приложении Apple «Команды». Встроенный помощник принимает только точные текстовые команды `on` и `off`, не возвращает результат и недоступен в меню «Поделиться», Spotlight, быстрых действиях и интерфейсе экрана блокировки. Он может работать, пока Mac заблокирован. Приложение не получает список других ваших быстрых команд и не просматривает их.

Автоматический режим включает оба параметра при подключении отмеченного дисплея с электронными чернилами и отключает их после отключения последнего отмеченного дисплея. Выход из приложения также отключает оба параметра.

</details>
