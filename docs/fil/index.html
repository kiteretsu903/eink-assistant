01 / ANO ANG GINAGAWA NG MGA CONTROL

Piliin ang control
para sa nilalaman.

Pinadidilim ng Contrast ng Teksto ang mga pahina para sa pagbabasa. Inilalantad ng Pagpapahusay ng Video ang madidilim na detalye ng larawan. Nakatutulong ang Saturation at RGB sa mga de-kulay na e‑ink panel.

Mga ilustrasyong preview. Nag-iiba ang resulta ayon sa panel at pinagmulang materyal.

02 / MGA DETALYE NG TAMPOK

MAC AT WINDOWS

Magkakaparehong control.
Mga limitasyong nakadepende sa system.

Ginagamit ng app ang mga pampublikong control ng display na available sa bawat operating system. Itinatago o ipinapaliwanag ang mga hindi suportadong control.

PAREHO
Contrast ng Teksto, Pagpapahusay ng Video, mga kurba, preset, at setting bawat display.
macOS LAMANG
Bawasan ang Pagkislap at pangangasiwa ng Night Shift / True Tone bawat display.
KULAY SA WINDOWS
Mga angkop na system na Windows 10 2004 at Windows 11 21H2+; nakadepende ang pagiging available sa system at hardware.

01 / PAGBABASA

Padilimin ang mapusyaw na teksto

  • Nag-aalok ang Contrast ng Teksto ng apat na antas para sa mga pahinang mababa ang contrast.
  • Gamitin ito para sa pagbabasa; hiwalay ito sa Pagpapahusay ng Video.

02 / MGA LARAWAN + VIDEO

Ilantad ang madidilim na detalye

  • Pinapaliwanag ng Pagpapahusay ng Video ang detalye sa madidilim na bahagi ng mga larawan at video.
  • I-off ito para sa pagbabasa dahil pinapaliwanag din nito ang madilim na teksto.

03 / DE-KULAY NA E‑INK

Ayusin ang saturation at RGB

  • Gumamit ng mga preset o direktang control upang bumawi sa limitadong saklaw ng kulay.
  • Nakadepende ang pagiging available sa operating system, GPU, driver, at paraan ng pagkakakonekta ng display.

04 / BAWAT DISPLAY

Panatilihin ang mga setting para sa bawat panel

  • Markahan lamang ang mga e‑ink display na gusto mong baguhin ng app.
  • Mag-save ng mga kurba para sa iba't ibang display at ibalik ang mga setting sa dati kapag isinara ang app.

03 / OPSYONAL NA MAS PINONG PAGSASAAYOS

Ayusin ang kurba
kapag hindi sapat ang mga preset.

Baguhin ang punto ng likô, gamma, puntong itim, at puntong puti habang tinitingnan ang kurba.

Mag-save ng hanggang limang pinangalanang preset. Hiwalay na iniimbak ang mga setting para sa bawat display.

macOS 2.6

I-install sa Mac

  1. I-download at buksan ang DMG.
  2. I-drag ang E‑Ink Assistant papunta sa Applications.
  3. Subukang buksan ang app nang isang beses. Kung bina-block ito ng macOS, buksan ang Mga Setting ng System → Privacy & Seguridad at piliin ang Buksan Pa Rin.

Independiyenteng binuong software ito at wala pa sa App Store sa kasalukuyan. Magpapakita ang macOS ng babalang hindi ito ma-verify sa unang pagbukas. Ganap na open source ang code, kaya maaari mo itong suriin bago magpasiyang gamitin ito.

Kung hindi lumalabas ang “Buksan Pa Rin”

Pagkatapos ilipat ang app sa Applications, buksan ang Terminal at patakbuhin:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

I-install sa Windows

  1. I-download at patakbuhin ang Setup file.
  2. Aprubahan ang hiling ng administrator.
  3. Buksan ang E‑Ink Assistant mula sa Start menu o system tray.

Para sa Windows 7 SP1 hanggang Windows 11 sa mga x64 na computer. Nakadepende ang mga available na control sa bersyon ng Windows, GPU, driver, at koneksyon ng display.
