01 / HVA KONTROLLENE GJØR

Velg kontrollen
som passer til innholdet.

Tekstkontrast gjør lesesider mørkere. Videoforbedring henter frem detaljer i mørke bilder. Metning og RGB hjelper e-blekkskjermer med farger.

Illustrative forhåndsvisninger. Resultatene varierer med skjermen og kildematerialet.

02 / FUNKSJONSDETALJER

MAC MOT WINDOWS

Felles kontroller.
Systemspesifikke begrensninger.

Appen bruker de offentlige skjermkontrollene som er tilgjengelige i hvert operativsystem. Kontroller som ikke støttes, skjules eller forklares.

BEGGE
Tekstkontrast, Videoforbedring, kurver, forhåndsinnstillinger og innstillinger per skjerm.
BARE macOS
Reduser flimring og håndtering av Night Shift / True Tone per skjerm.
FARGER I WINDOWS
Aktuelle Windows 10 2004- og Windows 11 21H2+-systemer; tilgjengeligheten avhenger av system og maskinvare.

01 / LESING

Gjør svak tekst mørkere

  • Tekstkontrast har fire nivåer for sider med lav kontrast.
  • Bruk den til lesing; den er atskilt fra Videoforbedring.

02 / BILDER + VIDEO

Hent frem mørke detaljer

  • Videoforbedring lysner skyggedetaljer i bilder og video.
  • Slå den av ved lesing, siden den også gjør mørk tekst lysere.

03 / E-BLEKK MED FARGER

Juster metning og RGB

  • Bruk forhåndsinnstillinger eller direkte kontroller for å kompensere for et begrenset fargerom.
  • Tilgjengeligheten avhenger av operativsystem, GPU, driver og signalvei til skjermen.

04 / PER SKJERM

Behold egne innstillinger for hver skjerm

  • Merk bare e-blekkskjermene du vil at appen skal endre.
  • Lagre kurver for ulike skjermer og gjenopprett innstillingene når appen avsluttes.

03 / VALGFRI FINJUSTERING

Juster kurven
når forhåndsinnstillingene ikke er nok.

Endre knekkpunkt, gamma, svartpunkt og hvitpunkt mens du ser kurven.

Lagre opptil fem navngitte forhåndsinnstillinger. Innstillingene lagres separat for hver skjerm.

macOS 2.6

Installer på Mac

  1. Last ned og åpne DMG-filen.
  2. Dra E‑Ink Assistant til Programmer.
  3. Prøv å åpne appen én gang. Hvis macOS blokkerer den, åpner du Systeminnstillinger → Personvern og sikkerhet og velger Åpne likevel.

Dette er uavhengig utviklet programvare som foreløpig ikke finnes i App Store. macOS viser en advarsel om at appen ikke kan verifiseres første gang du åpner den. Koden er helt åpen, så du kan se gjennom den før du bestemmer deg for å bruke appen.

Hvis «Åpne likevel» ikke vises

Etter at du har flyttet appen til Programmer, åpner du Terminal og kjører:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Installer på Windows

  1. Last ned og kjør installasjonsfilen.
  2. Godkjenn forespørselen om administratortilgang.
  3. Åpne E‑Ink Assistant fra Start-menyen eller systemstatusfeltet.

For Windows 7 SP1 til Windows 11 på x64-datamaskiner. Tilgjengelige kontroller avhenger av Windows-versjon, GPU, driver og skjermtilkobling.
