01 / ส่วนควบคุมทำอะไรได้บ้าง

คอนทราสต์ข้อความทำให้หน้าอ่านเข้มขึ้น ปรับภาพให้ชัดขึ้นเผยรายละเอียดในภาพมืด ความอิ่มสีและ RGB ช่วยจอ e‑ink สี

ภาพตัวอย่างเพื่ออธิบาย ผลลัพธ์แตกต่างกันตามจอและเนื้อหาต้นฉบับ

ทั้งสองระบบ

01 / การอ่าน

ทำให้ข้อความจางเข้มขึ้น

  • คอนทราสต์ข้อความ มีสี่ระดับสำหรับหน้าที่มีคอนทราสต์ต่ำ
  • ใช้สำหรับการอ่าน โดยแยกจากปรับภาพให้ชัดขึ้น

02 / ภาพถ่าย + วิดีโอ

เผยรายละเอียดส่วนมืด

  • ปรับภาพให้ชัดขึ้น ยกรายละเอียดส่วนมืดในภาพถ่ายและวิดีโอ
  • ปิดเมื่ออ่าน เพราะทำให้ข้อความสีเข้มจางลงด้วย

03 / E‑INK สี

ปรับความอิ่มสีและ RGB

  • ใช้ค่าที่ตั้งไว้หรือปรับโดยตรงเพื่อชดเชยขอบเขตสีที่จำกัด
  • ความพร้อมใช้งานขึ้นอยู่กับระบบปฏิบัติการ GPU ไดรเวอร์ และเส้นทางการแสดงผล

04 / แยกแต่ละจอ

เก็บการตั้งค่าไว้กับแต่ละจอ

  • ทำเครื่องหมายเฉพาะจอ e‑ink ที่ต้องการให้แอปปรับ
  • บันทึกเส้นโค้งสำหรับจอต่างๆ และคืนค่าการตั้งค่าเมื่อออกจากแอป

03 / ปรับละเอียดเพิ่มเติม

ปรับเส้นโค้ง
เมื่อค่าที่ตั้งไว้ยังไม่พอ

เปลี่ยนจุดหักโค้ง แกมมา จุดดำ และจุดขาวขณะดูเส้นโค้ง

บันทึกค่าที่ตั้งไว้พร้อมชื่อได้สูงสุดห้าชุด การตั้งค่าจะเก็บแยกสำหรับแต่ละจอ

คอนทราสต์ข้อความสี่ระดับ: ปานกลาง มาก คม ทึบเช่นเดียวกับ macOS
ปรับภาพให้ชัดขึ้นสามระดับ: เล็กน้อย ปานกลาง มากเช่นเดียวกับ macOS
เส้นโค้งขั้นสูงและค่าที่ตั้งไว้ตัวแก้ไขเส้นโค้งแบบสดและค่าที่ตั้งไว้พร้อมชื่อห้าชุดเช่นเดียวกับ macOS
ความอิ่มสีและ RGBโปรไฟล์สีแยกแต่ละจอ ความอิ่มสี 0%–300% และ RGB 0%–200%ใช้ได้บนระบบ Windows 10 2004 และ Windows 11 21H2+ ที่เข้ากันได้ วิธีที่ใช้ได้ขึ้นอยู่กับระบบและฮาร์ดแวร์
ลดการสั่นไหวใช้ได้บนจอภายนอกที่รองรับ เปิดเมื่อทำเครื่องหมายจอว่าเป็น e‑inkใช้ไม่ได้ Windows ไม่มีส่วนควบคุมดิเทอริงแบบสาธารณะที่เป็นมาตรฐานเดียวกันสำหรับแต่ละจอ และระบบ Windows ส่วนใหญ่อาจไม่จำเป็นต้องใช้
ลดความโปร่งใสและการเคลื่อนไหวใช้ได้ผ่านตัวช่วยที่ผู้ใช้ยืนยันเพียงครั้งเดียวใช้ได้ตั้งแต่ Windows 7 SP1 ผ่าน API ระบบที่เข้ากันได้
โหมดสว่างของระบบไม่เปลี่ยนแปลงโหมดสว่างของ Windows เฉพาะระหว่างการใช้งานแอป บน Windows 10 1903+
Night Shift / แสงกลางคืนยกเว้น Night Shift และ True Tone แยกแต่ละจอ ต้องได้รับอนุญาตจากผู้ดูแลระบบและเชื่อมต่อใหม่การตั้งค่าแสงกลางคืนตั้งแต่ Windows 10 1703+ และส่วนควบคุมปิดแสงกลางคืนโดยตรงบน Windows 11 24H2+
จอแบบสะท้อน / ทำซ้ำจอจริงที่สะท้อนภาพยังเลือกแยกแต่ละจอได้เส้นโค้งโทนสีมีผลต่อแหล่งภาพร่วม ความอิ่มสีและ RGB ต้องใช้โหมดขยาย
คืนค่าการเปลี่ยนแปลงเส้นโค้ง โปรไฟล์สี และดิเทอริงชั่วคราวจะคืนค่าเมื่อออก การยกเว้น Night Shift / True Tone จะคงอยู่การเปลี่ยนแปลงแกมมา สี ภาพ และแสงกลางคืนชั่วคราวจะคืนค่าเมื่อออก สีและแสงกลางคืนยังกู้คืนหลังออกผิดปกติด้วย
เปิดเมื่อเข้าสู่ระบบรองรับรองรับ
ภาษาส่วนติดต่อในรุ่นที่ดาวน์โหลดได้ปัจจุบันอังกฤษ จีนตัวย่อ จีนตัวเต็ม ญี่ปุ่นเช่นเดียวกับ macOS
สิทธิ์ผู้ดูแลระบบเฉพาะการยกเว้น Night Shift / True Tone ซึ่งเป็นทางเลือกโปรแกรมติดตั้งและแอปต้องใช้

macOS 2.6

ติดตั้งบน Mac

  1. ดาวน์โหลดและเปิด DMG
  2. ลาก E‑Ink Assistant ไปที่ แอปพลิเคชัน
  3. ลองเปิดแอปหนึ่งครั้ง หาก macOS บล็อก ให้เปิด การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย แล้วเลือก เปิดต่อไป

ซอฟต์แวร์นี้พัฒนาโดยอิสระและยังไม่มีใน App Store เมื่อเปิดครั้งแรก macOS จะแสดงคำเตือนว่าไม่สามารถตรวจสอบได้ โค้ดทั้งหมดเป็นโอเพนซอร์ส คุณจึงตรวจสอบก่อนตัดสินใจใช้งานได้

หากไม่พบ “เปิดต่อไป”

หลังย้ายแอปไปที่แอปพลิเคชัน ให้เปิด Terminal แล้วเรียกใช้:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"
