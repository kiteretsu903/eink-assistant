01 / WAXA KONTAROOLLADU QABTAAN

Dooro kontaroolka
ku habboon waxa aad daawanayso.

Kontrastiga qoraalku wuxuu madoobeeyaa bogagga akhriska. Hagaajinta fiidyowgu wuxuu soo saaraa faahfaahinta sawirka ee madow. Dheregga midabka iyo RGB waxay caawiyaan shaashadaha e-paper ee midabka leh.

Kuwani waa tusaalooyin muuqaal ah. Natiijadu waxay ku xiran tahay shaashadda iyo waxa la soo bandhigayo.

02 / FAAHFAAHINTA ASTAAMAHA

MAC IYO WINDOWS

Kontaroollo wadaag ah.
Xaddidaado nidaam kasta u gaar ah.

Abku wuxuu adeegsadaa kontaroollada shaashadda ee dadweynuhu heli karo ee nidaam kasta leeyahay. Kontaroollada aan la taageerin waa la qariyaa ama waa la sharxaa.

LABADABA

macOS OO KELIYA

MIDABKA WINDOWS
Nidaamyada ku habboon ee Windows 10 2004 iyo Windows 11 21H2+; helitaanku wuxuu ku xiran yahay nidaamka iyo qalabka.

01 / AKHRIS

Madoobee qoraalka khafiifka ah

  • Kontrastiga qoraalka wuxuu bixiyaa afar heer oo loogu talagalay bogagga kontrastigoodu hooseeyo.
  • U isticmaal akhriska; waa ka gooni Hagaajinta fiidyowga.

02 / SAWIRRO + FIIDYOW

Soo saar faahfaahinta madow

  • Hagaajinta fiidyowga wuxuu iftiimiyaa faahfaahinta madow ee sawirrada iyo fiidyowga.
  • Dami markaad akhrinayso, waayo qoraalka madow ayuu sidoo kale khafiifiyaa.

03 / E-PAPER MIDAB LEH

Hagaaji dheregga midabka iyo RGB

  • Adeegso dejimaha hore ama kontaroollada tooska ah si aad u magdhabto xadka midabbada ee kooban.
  • Helitaanku wuxuu ku xiran yahay nidaamka hawlgalka, GPU-ga, darawalka iyo jidka wax-soo-saarka shaashadda.

04 / SHAASHAD KASTA

Shaashad kasta dejinteeda u hay

  • Calaamadee oo keliya shaashadaha e-paper ee aad rabto in abku beddelo.
  • Kaydi qaloocyo shaashado kala duwan loogu talagalay, oo soo celi dejinta marka abku baxo.

03 / HAGAAJIN FAAHFAAHSAN OO IKHTIYAARI AH

Hagaaji qalooca
marka dejimaha hore aysan ku filnayn.

Beddel barta leexashada, gamma, barta madow iyo barta cad adigoo eegaya qalooca.

Kaydi ilaa shan dejin oo magac leh. Dejinta shaashad kasta gooni ayaa loo kaydiyaa.

macOS 14+ Apple silicon · Windows 7 SP1–11 x64

macOS 2.6

Ku rakib Mac

  1. Soo dejiso oo fur DMG-ga.
  2. U jiid E‑Ink Assistant galka Applications.
  3. Isku day inaad abka hal mar furto. Haddii macOS xannibo, fur Dejinta nidaamka → Asturnaanta iyo ammaanka oo dooro Si kastaba fur.

Kani waa barnaamij si madax-bannaan loo sameeyey, hadda kuma jiro App Store. macOS wuxuu marka ugu horraysa ku tusi doonaa digniin ah “lama xaqiijin karo”. Koodhku gebi ahaan waa il furan, sidaas darteed waad eegi kartaa ka hor intaadan go'aansan isticmaalka.

Haddii “Si kastaba fur” aanu muuqan

Ka dib markaad abka u wareejiso Applications, fur Terminal oo socodsii:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"
Soo dejiso macOS 2.6 ↓Haddii uu ku caawiyo, mashruuca xiddig ku sii GitHub ↗

WINDOWS 1.2

Ku rakib Windows

  1. Soo dejiso oo socodsii faylka rakibidda.
  2. Oggolow codsiga maamulaha.
  3. Ka fur E‑Ink Assistant liiska Bilowga ama saxanka nidaamka.

Kombiyuutarrada x64 ee Windows 7 SP1 ilaa Windows 11. Kontaroollada la heli karo waxay ku xiran yihiin nooca Windows, GPU-ga, darawalka iyo xidhitaanka shaashadda.
