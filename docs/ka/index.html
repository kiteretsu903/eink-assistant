01 / რას აკეთებს მართვის ელემენტები

აირჩიეთ მართვის ელემენტი
შიგთავსის მიხედვით.

ტექსტის კონტრასტი ამუქებს საკითხავ გვერდებს. ვიდეოს გაუმჯობესება აჩენს გამოსახულების ბნელ დეტალებს. გაჯერება და RGB ეხმარება ფერადი ელექტრონული მელნის პანელებს.

საილუსტრაციო მაგალითები. შედეგი პანელსა და საწყის მასალაზეა დამოკიდებული.

02 / შესაძლებლობების დეტალები

MAC და WINDOWS

საერთო მართვა.
სისტემისთვის სპეციფიკური შეზღუდვები.

აპი იყენებს თითოეულ ოპერაციულ სისტემაში ხელმისაწვდომ საჯარო ეკრანის მართვას. მხარდაუჭერელი ელემენტები დამალულია ან განმარტებულია.

01 / კითხვა

გაამუქეთ მკრთალი ტექსტი

  • ტექსტის კონტრასტი დაბალი კონტრასტის გვერდებისთვის ოთხ დონეს გთავაზობთ.
  • გამოიყენეთ კითხვისთვის; ის ვიდეოს გაუმჯობესებისგან განცალკევებულია.

02 / ფოტოები + ვიდეო

გამოაჩინეთ ბნელი დეტალები

  • ვიდეოს გაუმჯობესება აჩენს ჩრდილის დეტალებს ფოტოებსა და ვიდეოში.
  • კითხვისას გამორთეთ, რადგან ის ბნელ ტექსტსაც აღიავებს.

03 / ფერადი ელექტრონული მელანი

შეცვალეთ გაჯერება და RGB

  • ფერთა შეზღუდული დიაპაზონის შესავსებად გამოიყენეთ მზა პარამეტრები ან პირდაპირი მართვა.
  • ხელმისაწვდომობა ოპერაციულ სისტემაზე, GPU-ზე, დრაივერსა და გამოსახულების გზაზეა დამოკიდებული.

04 / თითოეული ეკრანი

შეინახეთ თითოეული პანელის პარამეტრები

  • მონიშნეთ მხოლოდ ის ელექტრონული მელნის ეკრანები, რომელთა შეცვლაც გსურთ აპით.
  • შეინახეთ მრუდები სხვადასხვა ეკრანისთვის და აღადგინეთ პარამეტრები აპიდან გასვლისას.

03 / არჩევითი ზუსტი მორგება

შეცვალეთ მრუდი
როცა მზა პარამეტრები საკმარისი არ არის.

მრუდის ყურებისას შეცვალეთ გარდატეხის წერტილი, გამა, შავი და თეთრი წერტილები.

შეინახეთ ხუთამდე სახელდებული მზა პარამეტრი. პარამეტრები ცალ-ცალკე ინახება თითოეული ეკრანისთვის.

macOS 2.6

Mac-ზე დაყენება

  1. ჩამოტვირთეთ და გახსენით DMG.
  2. გადაიტანეთ E‑Ink Assistant საქაღალდეში Applications.
  3. ერთხელ სცადეთ აპის გახსნა. თუ macOS დაბლოკავს, გახსენით სისტემის პარამეტრები → კონფიდენციალურობა & უსაფრთხოება და აირჩიეთ მაინც გახსნა.

ეს დამოუკიდებლად შექმნილი პროგრამაა და ამჟამად App Store-ში არ არის. პირველი გახსნისას macOS აჩვენებს გაფრთხილებას, რომ შემოწმება ვერ ხერხდება. კოდი სრულად ღიაა, ამიტომ გამოყენების გადაწყვეტილებამდე შეგიძლიათ შეისწავლოთ.

თუ „მაინც გახსნა“ არ ჩანს

აპის Applications-ში გადატანის შემდეგ გახსენით Terminal და შეასრულეთ:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"
