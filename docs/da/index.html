01 / HVAD KONTROLLERNE GØR

Vælg kontrollen
til indholdet.

Tekstkontrast gør læsesider mørkere. Videoforbedring viser mørke billeddetaljer. Mætning og RGB hjælper farve-e‑ink-paneler.

Illustrative forhåndsvisninger. Resultater varierer efter panel og kildemateriale.

02 / FUNKTIONER I DETALJER

MAC OG WINDOWS

Fælles kontroller.
Systemspecifikke begrænsninger.

Appen bruger de offentlige skærmkontroller, der findes i hvert operativsystem. Kontroller, der ikke understøttes, skjules eller forklares.

BEGGE
Tekstkontrast, Videoforbedring, kurver, forudindstillinger og indstillinger pr. skærm.
KUN macOS
Reducer flimren og håndtering af Night Shift / True Tone pr. skærm.
FARVER PÅ WINDOWS
Egnede systemer med Windows 10 2004 og Windows 11 21H2+; tilgængeligheden afhænger af system og hardware.

01 / LÆSNING

Gør svag tekst mørkere

  • Tekstkontrast tilbyder fire niveauer til sider med lav kontrast.
  • Brug den til læsning; den er adskilt fra Videoforbedring.

02 / FOTOS + VIDEO

Vis mørke detaljer

  • Videoforbedring lysner skyggedetaljer i fotos og video.
  • Slå den fra ved læsning, fordi den også lysner mørk tekst.

03 / FARVE-E‑INK

Juster mætning og RGB

  • Brug forudindstillinger eller direkte kontroller til at kompensere for et begrænset farverum.
  • Tilgængeligheden afhænger af operativsystem, GPU, driver og skærmforbindelse.

04 / PR. SKÆRM

Behold indstillingerne for hvert panel

  • Marker kun de e‑ink-skærme, som appen skal ændre.
  • Gem kurver til forskellige skærme, og gendan indstillingerne, når appen afsluttes.

03 / VALGFRI FINJUSTERING

Juster kurven,
når forudindstillinger ikke er nok.

Skift knækpunkt, gamma, sortpunkt og hvidpunkt, mens du ser kurven.

Gem op til fem navngivne forudindstillinger. Indstillinger gemmes separat for hver skærm.

macOS 2.6

Installer på Mac

  1. Download og åbn DMG-filen.
  2. Træk E‑Ink Assistant til Programmer.
  3. Prøv at åbne appen én gang. Hvis macOS blokerer den, skal du åbne Systemindstillinger → Anonymitet & sikkerhed og vælge Åbn alligevel.

Dette er uafhængigt udviklet software, som i øjeblikket ikke findes i App Store. macOS viser en advarsel om, at appen ikke kan verificeres, første gang du åbner den. Koden er helt åben, så du kan gennemgå den, før du beslutter, om du vil bruge appen.

Hvis “Åbn alligevel” ikke vises

Når du har flyttet appen til Programmer, skal du åbne Terminal og køre:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Installer på Windows

  1. Download og kør installationsfilen.
  2. Godkend administratoranmodningen.
  3. Åbn E‑Ink Assistant fra menuen Start eller meddelelsesområdet.

Til Windows 7 SP1 til Windows 11 på x64-computere. Tilgængelige kontroller afhænger af Windows-version, GPU, driver og skærmforbindelse.
