01 / QUÈ FAN ELS CONTROLS

Tria el control
segons el contingut.

Contrast del text enfosqueix les pàgines de lectura. Millora del vídeo revela els detalls foscos de les imatges. Saturació i RGB ajuden les pantalles de tinta electrònica en color.

Previsualitzacions il·lustratives. Els resultats varien segons la pantalla i el material original.

02 / DETALLS DE LES FUNCIONS

MAC I WINDOWS

Controls compartits.
Límits propis de cada sistema.

L'app fa servir els controls públics de pantalla disponibles a cada sistema operatiu. Els controls no compatibles s'amaguen o s'expliquen.

TOTS DOS
Contrast del text, Millora del vídeo, corbes, preajustos i configuració per pantalla.
NOMÉS macOS
Reducció del tremolor i gestió de Night Shift / True Tone per pantalla.
COLOR A WINDOWS
Sistemes Windows 10 2004 i Windows 11 21H2+ aplicables; la disponibilitat depèn del sistema i del maquinari.

01 / LECTURA

Enfosqueix el text pàl·lid

  • Contrast del text ofereix quatre nivells per a pàgines de contrast baix.
  • Fes-lo servir per llegir; és independent de Millora del vídeo.

02 / FOTOS + VÍDEO

Revela els detalls foscos

  • Millora del vídeo aclareix el detall de les ombres de fotos i vídeos.
  • Desactiva-la per llegir, perquè també aclareix el text fosc.

03 / TINTA ELECTRÒNICA EN COLOR

Ajusta la saturació i l'RGB

  • Fes servir preajustos o controls directes per compensar una gamma cromàtica limitada.
  • La disponibilitat depèn del sistema operatiu, la GPU, el controlador i la via de visualització.

04 / PER PANTALLA

Conserva els ajustos de cada pantalla

  • Marca només les pantalles de tinta electrònica que vulguis modificar amb l'app.
  • Desa corbes per a pantalles diferents i restaura els ajustos quan surtis de l'app.

03 / AJUST FI OPCIONAL

Ajusta la corba
quan els preajustos no siguin suficients.

Canvia el punt de flexió, Gamma, el punt negre i el punt blanc mentre observes la corba.

Desa fins a cinc preajustos amb nom. La configuració es desa per separat per a cada pantalla.

macOS 2.6

Instal·la al Mac

  1. Descarrega i obre el DMG.
  2. Arrossega E‑Ink Assistant a Aplicacions.
  3. Prova d'obrir l'app una vegada. Si macOS la bloqueja, obre Configuració del Sistema → Privacitat & Seguretat i selecciona Obre igualment.

Aquest programari s'ha desenvolupat de manera independent i actualment no és a l'App Store. macOS mostrarà un avís que no el pot verificar la primera vegada que l'obris. El codi és completament obert, de manera que el pots revisar abans de decidir si el vols fer servir.

Si no apareix «Obre igualment»

Després de moure l'app a Aplicacions, obre el Terminal i executa:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Instal·la al Windows

  1. Descarrega i executa el fitxer d'instal·lació.
  2. Aprova la sol·licitud d'administrador.
  3. Obre E‑Ink Assistant des del menú Inici o la safata del sistema.

Per a Windows 7 SP1 fins a Windows 11 en ordinadors x64. Els controls disponibles depenen de la versió de Windows, la GPU, el controlador i la connexió de la pantalla.
