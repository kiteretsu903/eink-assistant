01 / ЧТЕНИЕ

Сделайте бледный текст темнее

  • Контрастность текста предлагает четыре уровня для страниц с низкой контрастностью.
  • Используйте для чтения; эта настройка работает отдельно от улучшения видео.

02 / ФОТО + ВИДЕО

Раскройте детали в тенях

  • Улучшение видео осветляет детали в тенях на фотографиях и видео.
  • Отключайте для чтения, поскольку эта функция также осветляет тёмный текст.

03 / ЦВЕТНЫЕ ЭЛЕКТРОННЫЕ ЧЕРНИЛА

Настройте насыщенность и RGB

  • Используйте предустановки или ручные настройки, чтобы компенсировать ограниченный цветовой охват.
  • Доступность зависит от операционной системы, видеокарты, драйвера и способа подключения дисплея.

04 / ДЛЯ КАЖДОГО ДИСПЛЕЯ

Храните настройки каждой панели

  • Отметьте только те дисплеи с электронными чернилами, которые приложение должно изменять.
  • Сохраняйте кривые для разных дисплеев и восстанавливайте исходные настройки при выходе из приложения.

03 / ДОПОЛНИТЕЛЬНАЯ ТОЧНАЯ НАСТРОЙКА

Настройте кривую,
когда предустановок недостаточно.

Изменяйте точку перегиба, гамму, точку чёрного и точку белого, наблюдая за кривой.

Сохраните до пяти именованных предустановок. Настройки хранятся отдельно для каждого дисплея.

macOS 2.6

Установка на Mac

  1. Скачайте и откройте DMG.
  2. Перетащите E‑Ink Assistant в папку Программы.
  3. Попробуйте открыть приложение один раз. Если macOS заблокирует его, откройте Системные настройки → Конфиденциальность & безопасность и выберите Всё равно открыть.

Это независимо разработанное приложение, которое пока отсутствует в App Store. При первом запуске macOS покажет предупреждение о невозможности проверки. Исходный код полностью открыт: вы можете изучить его, прежде чем решать, использовать ли приложение.

Если кнопка «Всё равно открыть» не появляется

После перемещения приложения в папку «Программы» откройте Терминал и выполните:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Установка в Windows

  1. Скачайте и запустите установочный файл Setup.
  2. Подтвердите запрос прав администратора.
  3. Откройте E‑Ink Assistant из меню «Пуск» или области уведомлений.

Для систем от Windows 7 SP1 до Windows 11 на компьютерах x64. Доступные настройки зависят от версии Windows, видеокарты, драйвера и подключения дисплея.
