01 / LÄSNING

Gör svag text mörkare

  • Textkontrast ger fyra nivåer för sidor med låg kontrast.
  • Använd det vid läsning; det är en separat funktion från Videoförbättring.

02 / FOTON + VIDEO

Lyft fram mörka detaljer

  • Videoförbättring lyfter fram skuggdetaljer i foton och video.
  • Stäng av den vid läsning eftersom den även gör mörk text ljusare.

03 / E-PAPPER I FÄRG

Justera mättnad och RGB

  • Använd förinställningar eller direkta reglage för att kompensera för ett begränsat färgomfång.
  • Tillgängligheten beror på operativsystem, GPU, drivrutin och skärmens signalväg.

04 / PER SKÄRM

Behåll inställningarna för varje skärm

  • Markera bara de e-pappersskärmar som du vill att appen ska ändra.
  • Spara kurvor för olika skärmar och återställ inställningar när appen avslutas.

03 / VALFRI FINJUSTERING

Justera kurvan
när förinställningar inte räcker.

Ändra knäpunkt, gamma, svartpunkt och vitpunkt medan du ser kurvan.

Spara upp till fem namngivna förinställningar. Inställningar lagras separat för varje skärm.

macOS 2.6

Installera på Mac

  1. Ladda ned och öppna DMG-filen.
  2. Dra E‑Ink Assistant till Program.
  3. Försök öppna appen en gång. Om macOS blockerar den öppnar du Systeminställningar → Integritet och säkerhet och väljer Öppna ändå.

Det här är oberoende utvecklad programvara som för närvarande inte finns i App Store. macOS visar en varning om att appen inte kan verifieras första gången du öppnar den. Källkoden är helt öppen, så du kan granska den innan du bestämmer dig för att använda appen.

Om ”Öppna ändå” inte visas

När du har flyttat appen till Program öppnar du Terminal och kör:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Installera på Windows

  1. Ladda ned och kör installationsfilen.
  2. Godkänn begäran om administratörsbehörighet.
  3. Öppna E‑Ink Assistant från Start-menyn eller meddelandefältet.

För Windows 7 SP1 till Windows 11 på x64-datorer. Tillgängliga reglage beror på Windows-version, GPU, drivrutin och skärmanslutning.
