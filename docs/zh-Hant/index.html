01 / 控制項的作用

根據內容
選擇控制項。

「文字對比度」加深閱讀頁面的文字；「影片暗部增強」呈現影像暗部細節；彩度與 RGB 則適用於彩色電子紙面板。

以上為效果示意。實際結果依面板與原始素材而異。

01 / 閱讀

加深淡色文字

  • 文字對比度為低對比度頁面提供四種等級。
  • 適合閱讀時使用；與「影片暗部增強」分開運作。

02 / 照片與影片

呈現暗部細節

  • 影片暗部增強提亮照片與影片的暗部細節。
  • 閱讀時請關閉，因為它也會讓深色文字變淡。

03 / 彩色電子紙

調整彩度與 RGB

  • 使用預設或直接調整控制項，補償有限的色域。
  • 是否可用取決於作業系統、GPU、驅動程式與顯示輸出路徑。

04 / 各顯示器獨立設定

為每台面板保留專屬設定

  • 僅標記你希望本 App 調整的電子紙顯示器。
  • 為不同顯示器儲存曲線，並在結束 App 時還原設定。

03 / 選用微調

當預設不敷需求
就自行調整曲線。

一邊查看曲線，一邊調整轉折點、Gamma、黑點與白點。

最多可儲存五組具名稱的預設。每台顯示器的設定會分開儲存。

macOS 2.6

在 Mac 上安裝

  1. 下載並開啟 DMG。
  2. 將 E‑Ink Assistant 拖入應用程式。
  3. 先嘗試開啟 App 一次。如果 macOS 阻擋開啟，請前往系統設定 → 隱私權與安全性，然後選擇強制打開。

這是獨立開發的軟體，目前未上架 App Store。首次開啟時，macOS 會顯示「無法驗證」警告。程式碼完全開放，你可以先檢視，再決定是否使用。

如果未出現「強制打開」

將 App 移至「應用程式」後，開啟「終端機」並執行：

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"
