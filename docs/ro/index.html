01 / LECTURĂ

Întunecați textul palid

  • Contrastul textului oferă patru niveluri pentru paginile cu contrast redus.
  • Folosiți-l pentru lectură; este separat de Îmbunătățire video.

02 / FOTOGRAFII + VIDEO

Dezvăluiți detaliile întunecate

  • Îmbunătățire video scoate în evidență detaliile din umbre ale fotografiilor și videoclipurilor.
  • Dezactivați opțiunea pentru lectură, deoarece luminează și textul întunecat.

03 / E-INK COLOR

Ajustați saturația și RGB

  • Folosiți presetări sau comenzi directe pentru a compensa gama limitată de culori.
  • Disponibilitatea depinde de sistemul de operare, GPU, driver și calea de afișare.

04 / PENTRU FIECARE ECRAN

Păstrați setările fiecărui ecran

  • Marcați doar ecranele e-ink pe care doriți să le modifice aplicația.
  • Salvați curbe pentru ecrane diferite și restabiliți setările la închiderea aplicației.

03 / AJUSTARE FINĂ OPȚIONALĂ

Ajustați curba
când presetările nu sunt suficiente.

Modificați pragul de tranziție, gamma, punctul de negru și punctul de alb în timp ce vizualizați curba.

Salvați până la cinci presetări denumite. Setările sunt păstrate separat pentru fiecare ecran.

macOS 2.6

Instalare pe Mac

  1. Descărcați și deschideți DMG-ul.
  2. Trageți E‑Ink Assistant în Aplicații.
  3. Încercați să deschideți aplicația o dată. Dacă macOS o blochează, deschideți Configurări sistem → Intimitate & securitate și selectați Deschide oricum.

Acest software este dezvoltat independent și nu este disponibil momentan în App Store. macOS va afișa la prima deschidere un avertisment că aplicația nu poate fi verificată. Codul este complet deschis, astfel încât îl puteți examina înainte de a decide dacă folosiți aplicația.

Dacă „Deschide oricum” nu apare

După mutarea aplicației în Aplicații, deschideți Terminal și executați:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Instalare pe Windows

  1. Descărcați și executați fișierul de instalare.
  2. Aprobați solicitarea de administrator.
  3. Deschideți E‑Ink Assistant din meniul Start sau din zona de notificare.

Pentru Windows 7 SP1 până la Windows 11 pe calculatoare x64. Comenzile disponibile depind de versiunea Windows, GPU, driver și conexiunea ecranului.
