변경 기록

버전 2.6

2026년 9월 2일

미러링 디스플레이 지원을 개선했습니다.

  • 하드웨어로 미러링된 보조 디스플레이도 개별적으로 선택할 수 있으며 물리 출력별로 조정됩니다.
  • 미러링과 확장 레이아웃을 전환하면 디스플레이 설정을 신속히 갱신하고 다시 적용합니다.
  • 재적용과 종료 시 정리는 선택한 전자잉크 패널에만 적용되며, 연결된 미러링 디스플레이도 포함합니다.
  • 설정 도움말에서 모니터 자체 메뉴를 사용하도록 명확히 안내합니다.

버전 2.5

2026년 9월 2일

간결한 하드웨어 설정 안내를 추가했습니다.

  • 조절 패널 위에 닫을 수 있는 안내가 표시되며 Bigme B251 Pro 예시가 포함됩니다.
  • ‘확인’은 현재 실행 중에만 안내를 숨기며, ‘다시 표시하지 않기’는 재실행 후에도 유지됩니다.
  • 시작 패널을 아이콘과 함께 표시되는 간결한 설정 안내 세 항목으로 바꿨습니다.
  • 선택 목록에서 내장 디스플레이가 외장 디스플레이 뒤에 표시됩니다.

버전 2.4

2026년 9월 1일

패널 높이가 현재 화면에 맞춰집니다.

  • 조절 패널은 메뉴 막대 아이콘이 있는 화면의 사용 가능한 높이를 따릅니다.
  • 긴 콘텐츠는 스크롤되며 Dock 또는 화면 가장자리 위에 40포인트의 여백을 남깁니다. 짧은 패널은 콘텐츠에 맞는 높이를 유지합니다.

버전 2.3

2026년 9월 1일

텍스트 명암 프리셋 값을 변경했습니다.

  • ‘중간’은 이전의 ‘강하게’ 곡선을 사용합니다. ‘강하게’, ‘선명하게’, ‘진하게’ 순으로 더 어두워집니다.
  • ‘선명하게’는 감마 5.00과 블랙 포인트 0.10을 사용합니다. ‘진하게’는 감마 6.00과 블랙 포인트 0.34를 사용합니다. 둘 다 회색 세부 표현을 더 많이 없애고 가장자리를 더 뚜렷하게 만듭니다.

버전 2.2

2026년 8월 14일

‘작동 방식’의 언어 전환을 수정했습니다.

  • 앱 언어를 바꾸면 섹션 제목과 ‘더 보기 / 간략히 보기’ 버튼이 즉시 갱신됩니다.

버전 2.1

2026년 8월 14일

설정 도우미를 업데이트했습니다.

  • Mac이 잠겨 있어도 도우미를 실행할 수 있어 연결 해제와 정리 과정에서 단축어 경고가 나타나지 않습니다.
  • v2.0에서 업그레이드하는 사용자는 이름이 바뀐 도우미를 한 번 추가해야 하며, 그 후 이전 도우미를 삭제해도 됩니다.

버전 2.0

2026년 8월 13일

디스플레이 조절 기능, 언어, DMG 설치 파일을 추가했습니다.

  • 디스플레이별 RGB, Night Shift, True Tone 조절 기능을 추가했습니다.
  • 사용자가 확인한 단축어 도우미를 통한 투명도 및 동작 줄이기 제어를 추가했습니다.
  • 영어, 중국어 간체, 중국어 번체, 일본어를 추가했습니다.

버전 1.1

디스플레이별 Night Shift 및 True Tone 제어를 추가했습니다.

  • 이 변경에는 관리자 암호와 디스플레이 재연결이 필요합니다. 앱을 종료해도 원래대로 되돌아가지 않습니다.

버전 1.0

최초 릴리스.

  • 깜박임 줄이기, 채도, 텍스트 명암, 영상 개선, 사용자 지정 색조 곡선, 곡선 저장 슬롯, 종료 시 디스플레이 복원을 추가했습니다.

버전 1.2

최신

색상 조절 복구를 개선했습니다.

  • Windows가 색상 처리 경로를 제공하지만 앱의 상태 변경은 허용하지 않을 때 잘못 표시되던 기능 실패 경고를 수정했습니다.
  • 복제 모드에서 색상 제어가 일시적으로 비활성화되어도 복구 데이터를 유지하며, 제어 가능한 디스플레이 레이아웃으로 돌아오면 복원합니다.

버전 1.1

Windows 최초 릴리스.

  • 디스플레이별 텍스트 명암, 영상 개선, 고급 곡선, 프리셋, 전자잉크 디스플레이 선택을 추가했습니다.
  • 호환되는 채도, RGB, Windows 라이트 모드, 야간 모드 조절과 복원 및 비정상 종료 복구 기능을 추가했습니다.
  • 복제 디스플레이 처리, 시스템 트레이 시작 안내, 로그인 시 실행, 업데이트, 다국어 설치 프로그램을 추가했습니다.
