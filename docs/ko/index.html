01 / 조절 기능 안내

콘텐츠에 맞는
조절 기능을 선택하세요.

텍스트 명암은 읽을 페이지의 글자를 어둡게 합니다. 영상 개선은 이미지의 어두운 부분을 드러냅니다. 채도와 RGB는 컬러 전자잉크 패널에 도움이 됩니다.

이해를 돕기 위한 예시입니다. 결과는 패널과 원본 콘텐츠에 따라 다릅니다.

02 / 기능 상세

MAC과 WINDOWS

공통 조절 기능.
시스템별 제한 사항.

앱은 각 운영 체제에서 제공하는 공개 디스플레이 제어 기능을 사용합니다. 지원되지 않는 조절 기능은 숨기거나 이유를 안내합니다.

공통
텍스트 명암, 영상 개선, 곡선, 프리셋, 디스플레이별 설정.
macOS 전용
깜박임 줄이기와 디스플레이별 Night Shift / True Tone 제어.
WINDOWS 색상
지원 조건을 충족하는 Windows 10 2004 및 Windows 11 21H2+ 시스템에서 사용 가능합니다. 사용 가능 여부는 시스템과 하드웨어에 따라 다릅니다.

01 / 읽기

희미한 글자를 더 어둡게

  • 텍스트 명암은 명암이 낮은 페이지를 위해 네 단계를 제공합니다.
  • 읽을 때 사용하세요. 영상 개선과는 별개의 기능입니다.

02 / 사진 + 동영상

어두운 부분까지 선명하게

  • 영상 개선은 사진과 동영상의 어두운 영역을 밝게 하여 세부 표현을 드러냅니다.
  • 어두운 글자도 밝아지므로 읽을 때는 끄세요.

03 / 컬러 전자잉크

채도와 RGB 조정

  • 프리셋이나 직접 조절 기능으로 제한된 색 영역을 보정하세요.
  • 사용 가능 여부는 운영 체제, GPU, 드라이버, 디스플레이 출력 경로에 따라 다릅니다.

04 / 디스플레이별 설정

패널마다 설정 유지

  • 앱으로 변경할 전자잉크 디스플레이만 선택하세요.
  • 서로 다른 디스플레이의 곡선을 저장하고 앱을 종료하면 설정을 원래대로 복원합니다.

03 / 선택적 세부 조정

프리셋만으로 부족하다면
곡선을 조정하세요.

곡선을 보면서 꺾임점, 감마, 블랙 포인트, 화이트 포인트를 변경하세요.

이름을 지정한 프리셋을 최대 다섯 개 저장하세요. 설정은 디스플레이별로 따로 저장됩니다.

macOS 2.6

Mac에 설치

  1. DMG를 다운로드하고 여세요.
  2. E‑Ink Assistant를 응용 프로그램으로 드래그하세요.
  3. 앱을 한 번 열어 보세요. macOS가 차단하면 시스템 설정 → 개인정보 보호 및 보안에서 확인 없이 열기를 선택하세요.

이 소프트웨어는 독립적으로 개발되었으며 현재 App Store에 등록되어 있지 않습니다. 처음 열 때 macOS에서 ‘확인할 수 없음’ 경고가 표시됩니다. 코드는 모두 공개되어 있으므로 사용 여부를 결정하기 전에 검토할 수 있습니다.

‘확인 없이 열기’가 나타나지 않는 경우

앱을 응용 프로그램으로 옮긴 다음 터미널을 열어 실행하세요:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Windows에 설치

  1. 설치 파일을 다운로드하고 실행하세요.
  2. 관리자 권한 요청을 승인하세요.
  3. 시작 메뉴 또는 시스템 트레이에서 E‑Ink Assistant를 여세요.

x64 컴퓨터의 Windows 7 SP1부터 Windows 11까지 지원합니다. 사용 가능한 조절 기능은 Windows 버전, GPU, 드라이버, 디스플레이 연결 방식에 따라 다릅니다.
