01 / OHUN TÍ ÀWỌN ÌṢÀKÓSO Ń ṢE

Yan ìṣàkóso
tó bá àkóónú mu.

Ìyàtọ̀ Ìmọ́lẹ̀ Ọ̀rọ̀ mú àwọn ojú ìwé kíkà ṣókùnkùn. Ìmúdára Fídíò ń fi àlàyé àwòrán dúdú hàn. Ìkún àwọ̀ àti RGB ń ran àwọn ojú-ìwò e‑ink aláwọ̀ lọ́wọ́.

Àwọn àwòrán àpẹẹrẹ. Àbájáde yàtọ̀ síra gẹ́gẹ́ bí ojú-ìwò àti ohun àkọ́kọ́.

02 / ÀLÀYÉ ÀWỌN ÀNÍMỌ́

MAC ÀTI WINDOWS

Àwọn ìṣàkóso kan náà.
Ààlà tó jẹ mọ́ ètò kọ̀ọ̀kan.

01 / KÍKÀ

Mú ọ̀rọ̀ tó rẹ̀ ṣókùnkùn

  • Ìyàtọ̀ Ìmọ́lẹ̀ Ọ̀rọ̀ ní ìpele mẹ́rin fún àwọn ojú ìwé tí ìyàtọ̀ ìmọ́lẹ̀ wọn kéré.
  • Lò ó fún kíkà; ó yàtọ̀ sí Ìmúdára Fídíò.

02 / FỌ́TÒ + FÍDÍÒ

Fi àlàyé dúdú hàn

  • Ìmúdára Fídíò mú àlàyé inú òjìji fọ́tò àti fídíò mọ́lẹ̀.
  • Pa á fún kíkà nítorí ó tún mú ọ̀rọ̀ dúdú fẹ́ẹ́rẹ́.

03 / E‑INK ALÁWỌ̀

Ṣètò ìkún àwọ̀ àti RGB

  • Lo àwọn ètò tí a ti pèsè tàbí ìṣàkóso tààrà láti ṣàfikún sí ààlà àwọ̀ tó kéré.
  • Wíwà rẹ̀ sinmi lórí ètò ìṣiṣẹ́, GPU, awakọ̀ àti ọ̀nà àfihàn.

04 / FÚN OJÚ-ÌWÒ KỌ̀Ọ̀KAN

Pa ètò mọ́ fún ojú-ìwò kọ̀ọ̀kan

  • Samì sí àwọn ojú-ìwò e‑ink tí o fẹ́ kí ohun èlò yí padà nìkan.
  • Fi àwọn ìlà pamọ́ fún ojú-ìwò tó yàtọ̀, kí o sì dá ètò padà nígbà jíjáde.

03 / ÀTÚNṢE PẸ̀LẸ́ TÍ O LÈ YAN

Ṣètò ìlà
nígbà tí ètò tí a ti pèsè kò tó.

Yí ibùdó ìtẹ̀, gamma, ibùdó dúdú àti ibùdó funfun padà nígbà tí o ń wo ìlà.

Fi ètò tí ó ní orúkọ tó márùn-ún pamọ́. A pa ètò mọ́ lọ́tọ̀ fún ojú-ìwò kọ̀ọ̀kan.

macOS 2.6

Fi sórí Mac

  1. Ṣe ìgbàsílẹ̀ DMG, kí o sì ṣí i.
  2. Fa E‑Ink Assistant sínú Applications.
  3. Gbìyànjú láti ṣí ohun èlò lẹ́ẹ̀kan. Bí macOS bá dí i, ṣí System Settings → Privacy & Security kí o sì yan Open Anyway.

A ṣe sọ́fitiwia yìí lọ́tọ̀, kò sì tíì sí lórí App Store. macOS máa fi ìkìlọ̀ “kò lè jẹ́rìí” hàn ní ìgbà àkọ́kọ́ tí o bá ṣí i. Orísun kóòdù ṣí síta pátápátá, nítorí náà o lè ṣàyẹ̀wò rẹ̀ kí o tó pinnu láti lò ó.

Bí “Open Anyway” kò bá hàn

Lẹ́yìn tí o bá gbé ohun èlò sínú Applications, ṣí Terminal kí o sì ṣiṣẹ́:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

  1. Ṣe ìgbàsílẹ̀ fáìlì ìfisóríẹ̀rọ, kí o sì ṣiṣẹ́ rẹ̀.
  2. Fọwọ́ sí ìbéèrè alábòójútó.
