01 / DESIGNED FOR macOS

A display utility
for macOS and e‑ink.

E‑Ink Assistant runs from the menu bar on macOS 14+ with Apple silicon. It targets only the external displays you mark as e‑ink, so your built-in Mac display and other monitors stay unchanged.

The core display controls need no permissions and do not install a separate background service.

01 / DISPLAY STABILITY

Steadier e‑ink output

  • Reduce Shaking and Motion removes visible dithering and simplifies slow-refresh macOS visuals.
  • Display following applies the selected profile when a marked display connects.

02 / READING & MEDIA

Reading and media

  • Text Contrast darkens faint text. Four levels: Medium, Strong, Sharp, and Solid.
  • Video Enhance reveals dark photo and video detail. Three levels: Subtle, Medium, and Strong.

03 / COLOR E‑INK

Color e‑ink control

  • Saturation and RGB offer six presets, a 0%–300% slider, and independent 0%–200% channel correction.
  • Per-display Night Shift and True Tone keeps macOS color-temperature processing off the e‑ink panel only.

04 / ADVANCED TUNING

Curves and presets

  • Full tone curve adjusts knee, gamma, black point, and white point with a live plot.
  • Five named slots and Shortcuts save profiles and automate display behavior.

02 / REAL IMPROVEMENTS

Small changes.
A much clearer page.

The app uses targeted tone transforms: darken what needs to be read, lift only the shadows that hide media detail, or recover color from a narrow-gamut panel.
