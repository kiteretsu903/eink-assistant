01 / READING

Make faint text darker

  • Text Contrast offers four levels for low-contrast pages.
  • Use it for reading; it is separate from Video Enhance.

02 / PHOTOS + VIDEO

Reveal dark detail

  • Video Enhance lifts shadow detail in photos and video.
  • Turn it off for reading because it also lightens dark text.

03 / COLOR E‑INK

Adjust saturation and RGB

  • Use presets or direct controls to compensate for a limited color gamut.
  • Availability depends on the operating system, GPU, driver, and display path.

04 / PER DISPLAY

Keep settings with each panel

  • Mark only the e‑ink displays you want the app to change.
  • Save curves for different displays and restore settings when the app exits.

03 / OPTIONAL FINE-TUNING

Adjust the curve
when presets are not enough.

Change knee, gamma, black point, and white point while viewing the curve.

Save up to five named presets. Settings are stored separately for each display.

macOS 2.6

Install on Mac

  1. Download and open the DMG.
  2. Drag E‑Ink Assistant into Applications.
  3. Try to open the app once. If macOS blocks it, open System Settings → Privacy & Security and select Open Anyway.

This is independently developed software and is not currently on the App Store. macOS will show an “unable to verify” warning the first time you open it. The code is fully open source, so you can review it before deciding whether to use it.

If “Open Anyway” does not appear

After moving the app to Applications, open Terminal and run:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Install on Windows

  1. Download and run the Setup file.
  2. Approve the administrator prompt.
  3. Open E‑Ink Assistant from the Start menu or system tray.

For Windows 7 SP1 through Windows 11 on x64 computers. Available controls depend on the Windows version, GPU, driver, and display connection.
