Veldu stillinguna
eftir efninu.

Sýnidæmi. Niðurstöður eru háðar skjá og upprunalegu efni.

02 / NÁNAR UM EIGINLEIKA

MAC OG WINDOWS

Sameiginlegar stillingar.
Takmarkanir hvers kerfis.

Forritið notar opnar skjástýringar sem eru tiltækar í hverju stýrikerfi. Stillingar sem ekki eru studdar eru faldar eða útskýrðar.

LITIR Í WINDOWS
Samhæf Windows 10 2004 og Windows 11 21H2+ kerfi; aðgengi er háð kerfi og vélbúnaði.

01 / LESTUR

Gerðu daufan texta dekkri

  • Birtuskil texta bjóða upp á fjögur stig fyrir síður með lítil birtuskil.
  • Notaðu fyrir lestur; þetta er aðskilið frá Myndbætingu.

02 / LJÓSMYNDIR + MYNDSKEIÐ

Dragðu fram dökk smáatriði

  • Myndbæting dregur fram smáatriði í skuggum ljósmynda og myndskeiða.
  • Slökktu við lestur því þetta lýsir líka dökkan texta.

03 / E‑INK LITASKJÁIR

Stilltu litmettun og RGB

  • Notaðu forstillingar eða beinar stillingar til að vega upp á móti takmörkuðu litasviði.
  • Aðgengi er háð stýrikerfi, skjákorti, rekli og skjátengingu.

04 / FYRIR HVERN SKJÁ

Varðveittu stillingar fyrir hvern skjá

  • Merktu aðeins þá e‑ink skjái sem þú vilt að forritið breyti.
  • Vistaðu ferla fyrir mismunandi skjái og endurheimtu stillingar þegar forritinu er lokað.

03 / VALFRJÁLS FÍNSTILLING

Stilltu ferilinn
þegar forstillingar duga ekki.

Breyttu beygjupunkti, gamma, svartpunkti og hvítpunkti um leið og þú skoðar ferilinn.

Vistaðu allt að fimm nafngreindar forstillingar. Stillingar eru vistaðar sérstaklega fyrir hvern skjá.

macOS 2.6

Setja upp á Mac

  1. Sæktu og opnaðu DMG-skrána.
  2. Dragðu E‑Ink Assistant í Applications.
  3. Prófaðu að opna forritið einu sinni. Ef macOS hindrar það skaltu opna Kerfisstillingar → Persónuvernd og öryggi og velja Opna samt.

Þetta er sjálfstætt þróaður hugbúnaður sem er ekki á App Store eins og er. macOS sýnir viðvörun um að ekki sé hægt að staðfesta forritið þegar þú opnar það í fyrsta sinn. Allur frumkóðinn er opinn svo þú getur skoðað hann áður en þú ákveður hvort þú viljir nota forritið.

Ef „Opna samt“ birtist ekki

Eftir að þú hefur fært forritið í Applications skaltu opna Terminal og keyra:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Setja upp á Windows

  1. Sæktu og keyrðu uppsetningarskrána.
  2. Samþykktu beiðnina um stjórnandaaðgang.
  3. Opnaðu E‑Ink Assistant úr upphafsvalmyndinni eða tilkynningasvæðinu.

Fyrir Windows 7 SP1 til Windows 11 á x64 tölvum. Tiltækar stillingar eru háðar Windows-útgáfu, skjákorti, rekli og skjátengingu.
