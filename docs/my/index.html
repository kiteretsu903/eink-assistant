01 / ထိန်းချုပ်မှုများ၏ အလုပ်လုပ်ပုံ

ထိန်းချုပ်မှုကို ရွေးပါ
အကြောင်းအရာနှင့် ကိုက်ညီအောင်။

စာသားအလင်းအမှောင်ကွာခြားမှုက စာဖတ်စာမျက်နှာများကို မည်းစေသည်။ ဗီဒီယိုမြှင့်တင်မှုက ပုံ၏ မှောင်သောအသေးစိတ်ကို ဖော်ပေးသည်။ အရောင်ပြည့်ဝမှုနှင့် RGB က ရောင်စုံ e-ink မျက်နှာပြင်များကို ကူညီပေးသည်။

ရှင်းပြရန် နမူနာပြသမှုများဖြစ်သည်။ ရလဒ်သည် မျက်နှာပြင်နှင့် မူရင်းအကြောင်းအရာပေါ် မူတည်သည်။

MAC နှင့် WINDOWS

အက်ပ်သည် လည်ပတ်စနစ်တစ်ခုစီတွင် ရနိုင်သော အများပြည်သူသုံး မျက်နှာပြင်ထိန်းချုပ်မှုများကို သုံးသည်။ မပံ့ပိုးသော ထိန်းချုပ်မှုများကို ဝှက်ထားသည် သို့မဟုတ် ရှင်းပြထားသည်။

နှစ်ခုလုံး

01 / စာဖတ်ခြင်း

ဖျော့သောစာသားကို ပိုမည်းစေပါ

  • စာသားအလင်းအမှောင်ကွာခြားမှု တွင် ကွာခြားမှုနည်းသော စာမျက်နှာများအတွက် အဆင့်လေးခု ရှိသည်။
  • စာဖတ်ရန် သုံးပါ။ ဗီဒီယိုမြှင့်တင်မှုနှင့် သီးခြားဖြစ်သည်။

02 / ဓာတ်ပုံ + ဗီဒီယို

မှောင်သောအသေးစိတ်ကို ဖော်ပါ

  • ဗီဒီယိုမြှင့်တင်မှု က ဓာတ်ပုံနှင့် ဗီဒီယိုများရှိ အရိပ်အသေးစိတ်ကို လင်းစေသည်။
  • မည်းသောစာသားကိုပါ ဖျော့စေသဖြင့် စာဖတ်ချိန်တွင် ပိတ်ပါ။

03 / ရောင်စုံ E‑INK

အရောင်ပြည့်ဝမှုနှင့် RGB ချိန်ညှိပါ

  • ကန့်သတ်ထားသော အရောင်အပိုင်းအခြားကို ဖြည့်ဆည်းရန် ကြိုတင်သတ်မှတ်ချက်များ သို့မဟုတ် တိုက်ရိုက်ထိန်းချုပ်မှုများ သုံးပါ။
  • ရရှိနိုင်မှုသည် လည်ပတ်စနစ်၊ GPU၊ ဒရိုင်ဘာနှင့် မျက်နှာပြင်လမ်းကြောင်းပေါ် မူတည်သည်။

04 / မျက်နှာပြင်အလိုက်

မျက်နှာပြင်တစ်ခုစီ၏ ဆက်တင်များ သိမ်းထားပါ

  • အက်ပ်မှ ပြောင်းစေလိုသော e-ink မျက်နှာပြင်များကိုသာ မှတ်ပါ။
  • မျက်နှာပြင်အမျိုးမျိုးအတွက် မျဉ်းကွေးများသိမ်းပြီး အက်ပ်မှထွက်ချိန်တွင် ဆက်တင်များကို မူလပြန်ထားပါ။

03 / ဆန္ဒအလျောက် အသေးစိတ်ချိန်ညှိမှု

မျဉ်းကွေးကို ချိန်ပါ
ကြိုတင်သတ်မှတ်ချက်များ မလုံလောက်သည့်အခါ။

မျဉ်းကွေးကို ကြည့်ရင်း ကွေးညွတ်မှတ်၊ Gamma၊ အနက်မှတ်နှင့် အဖြူမှတ်ကို ပြောင်းပါ။

အမည်ပေးထားသော ကြိုတင်သတ်မှတ်ချက် ငါးခုအထိ သိမ်းပါ။ ဆက်တင်များကို မျက်နှာပြင်တစ်ခုစီအတွက် သီးခြားသိမ်းသည်။

တုန်ခါမှုလျှော့ချရန်ပံ့ပိုးသော ပြင်ပမျက်နှာပြင်များတွင် ရသည်။ မျက်နှာပြင်ကို e-ink ဟု မှတ်လျှင် ဖွင့်သည်မရပါ။ Windows တွင် မျက်နှာပြင်အလိုက် တစ်ပြေးညီ အများပြည်သူသုံး dithering ထိန်းချုပ်မှု မရှိဘဲ Windows စနစ်အများစုတွင်လည်း လိုအပ်မည်မဟုတ်ပါ။
ဖောက်မြင်နိုင်မှု & လှုပ်ရှားမှု လျှော့ချရန်အသုံးပြုသူ တစ်ကြိမ်အတည်ပြုသော အကူကိရိယာမှတစ်ဆင့် ရသည်ကိုက်ညီသော စနစ် API များမှတစ်ဆင့် Windows 7 SP1 မှစ၍ ရသည်

Night Shift / ညအလင်းမျက်နှာပြင်အလိုက် Night Shift နှင့် True Tone မှ ချန်လှပ်ခြင်း၊ စီမံခန့်ခွဲသူ ခွင့်ပြုချက်နှင့် ပြန်ချိတ်ဆက်ရန် လိုသည်Windows 10 1703+ မှစ၍ ညအလင်းဆက်တင်များ၊ Windows 11 24H2+ တွင် ညအလင်းကို တိုက်ရိုက်ပိတ်နိုင်သော ထိန်းချုပ်မှု
ပုံတူ / ထပ်တူပြ မျက်နှာပြင်များပုံတူပြထားသော ရုပ်ပိုင်းမျက်နှာပြင်များကို တစ်ခုချင်း ရွေးနိုင်ဆဲဖြစ်သည်အရောင်အဆင့်မျဉ်းကွေးများက မျှဝေထားသော အရင်းအမြစ်ကို သက်ရောက်သည်။ အရောင်ပြည့်ဝမှုနှင့် RGB အတွက် တိုးချဲ့မုဒ် လိုသည်
ပြောင်းလဲမှုများကို မူလပြန်ထားခြင်းယာယီမျဉ်းကွေးများ၊ အရောင်ပရိုဖိုင်များနှင့် dithering ကို ထွက်ချိန်တွင် မူလပြန်ထားသည်။ Night Shift / True Tone မှ ချန်လှပ်ခြင်းက အမြဲကျန်သည်ယာယီ Gamma၊ အရောင်၊ အသွင်အပြင်နှင့် ညအလင်း ပြောင်းလဲမှုများကို ထွက်ချိန်တွင် မူလပြန်ထားသည်။ ပုံမှန်မဟုတ်ဘဲ ထွက်ပြီးနောက်လည်း အရောင်နှင့် ညအလင်းကို ပြန်ထားသည်
