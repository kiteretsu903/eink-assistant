01 / ПРИЗНАЧЕННЯ РЕГУЛЯТОРІВ

Виберіть регулятор
відповідно до вмісту.

Контрастність тексту затемнює сторінки для читання. Покращення відео виявляє деталі темних зображень. Насиченість і RGB допомагають кольоровим панелям з електронним чорнилом.

Ілюстративні приклади. Результати залежать від панелі та вихідного матеріалу.

02 / ДОКЛАДНО ПРО МОЖЛИВОСТІ

MAC І WINDOWS

Спільні регулятори.
Обмеження окремих систем.

Програма використовує загальнодоступні засоби керування дисплеями кожної операційної системи. Непідтримувані регулятори приховуються або супроводжуються поясненням.

ОБИДВІ ПЛАТФОРМИ
Контрастність тексту, покращення відео, криві, пресети та налаштування для кожного дисплея.
ЛИШЕ macOS
Зменшення мерехтіння та керування Night Shift / True Tone для кожного дисплея.
КОЛІР У WINDOWS
Відповідні системи Windows 10 2004 і Windows 11 21H2+; доступність залежить від системи й обладнання.

01 / ЧИТАННЯ

Зробіть блідий текст темнішим

  • Контрастність тексту пропонує чотири рівні для сторінок із низькою контрастністю.
  • Використовуйте для читання; це окрема від покращення відео функція.

02 / ФОТОГРАФІЇ + ВІДЕО

Виявіть темні деталі

  • Покращення відео освітлює деталі в тінях фотографій і відео.
  • Вимикайте для читання, оскільки функція також освітлює темний текст.

03 / КОЛЬОРОВЕ ЕЛЕКТРОННЕ ЧОРНИЛО

Регулюйте насиченість і RGB

  • Використовуйте пресети або пряме регулювання, щоб компенсувати обмежене колірне охоплення.
  • Доступність залежить від операційної системи, GPU, драйвера та шляху виведення зображення.

04 / ДЛЯ КОЖНОГО ДИСПЛЕЯ

Зберігайте налаштування кожної панелі

  • Позначайте лише ті дисплеї з електронним чорнилом, які програма має змінювати.
  • Зберігайте криві для різних дисплеїв і відновлюйте налаштування після виходу з програми.

03 / НЕОБОВ’ЯЗКОВЕ ТОЧНЕ НАЛАШТУВАННЯ

Налаштуйте криву,
якщо пресетів недостатньо.

Змінюйте точку перегину, гаму, точку чорного й точку білого, переглядаючи криву.

Зберігайте до п’яти іменованих пресетів. Налаштування зберігаються окремо для кожного дисплея.

macOS 2.6

Установлення на Mac

  1. Завантажте та відкрийте DMG.
  2. Перетягніть E‑Ink Assistant до Програми.
  3. Спробуйте відкрити програму один раз. Якщо macOS її блокує, відкрийте Системні параметри → Приватність і безпека та виберіть Відкрити попри це.

Це незалежно розроблене програмне забезпечення, яке наразі відсутнє в App Store. Під час першого відкриття macOS покаже попередження про неможливість перевірки. Код повністю відкритий, тож його можна переглянути, перш ніж вирішити, чи користуватися програмою.

Якщо «Відкрити попри це» не з’являється

Перемістивши програму до папки «Програми», відкрийте Термінал і виконайте:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Установлення на Windows

  1. Завантажте та запустіть інсталяційний файл.
  2. Підтвердьте запит адміністратора.
  3. Відкрийте E‑Ink Assistant з меню «Пуск» або області сповіщень.

Для Windows 7 SP1 — Windows 11 на комп’ютерах x64. Доступні регулятори залежать від версії Windows, GPU, драйвера та під’єднання дисплея.
