01 / DZIAŁANIE USTAWIEŃ

Wybierz ustawienie
odpowiednie do treści.

Kontrast tekstu przyciemnia strony do czytania. Ulepszanie wideo wydobywa szczegóły ciemnego obrazu. Nasycenie i RGB pomagają kolorowym panelom z papierem elektronicznym.

Podglądy ilustracyjne. Wyniki zależą od panelu i materiału źródłowego.

02 / SZCZEGÓŁY FUNKCJI

MAC A WINDOWS

Wspólne ustawienia.
Ograniczenia zależne od systemu.

Aplikacja korzysta z publicznych mechanizmów sterowania ekranami dostępnych w każdym systemie operacyjnym. Nieobsługiwane ustawienia są ukryte lub objaśnione.

OBIE PLATFORMY
Kontrast tekstu, ulepszanie wideo, krzywe, ustawienia wstępne i osobne ustawienia każdego ekranu.
TYLKO macOS
Ograniczanie migotania oraz obsługa Night Shift / True Tone dla poszczególnych ekranów.
KOLORY W WINDOWS
Zgodne systemy Windows 10 2004 i Windows 11 21H2+; dostępność zależy od systemu i sprzętu.

01 / CZYTANIE

Przyciemnij blady tekst

  • Kontrast tekstu oferuje cztery poziomy dla stron o niskim kontraście.
  • Używaj do czytania; działa niezależnie od ulepszania wideo.

02 / ZDJĘCIA + FILMY

Wydobądź szczegóły z cieni

  • Ulepszanie wideo rozjaśnia szczegóły w cieniach na zdjęciach i filmach.
  • Wyłącz je do czytania, ponieważ rozjaśnia również ciemny tekst.

03 / KOLOROWY PAPIER ELEKTRONICZNY

Dostosuj nasycenie i RGB

  • Użyj ustawień wstępnych lub ręcznych, aby skompensować ograniczoną gamę barw.
  • Dostępność zależy od systemu operacyjnego, karty graficznej, sterownika i ścieżki wyświetlania.

04 / OSOBNO DLA KAŻDEGO EKRANU

Zachowaj ustawienia każdego panelu

  • Oznacz tylko te ekrany z papierem elektronicznym, które aplikacja ma zmieniać.
  • Zapisuj krzywe dla różnych ekranów i przywracaj ustawienia po zamknięciu aplikacji.

03 / OPCJONALNE PRECYZYJNE DOSTRAJANIE

Dostosuj krzywą,
gdy ustawienia wstępne nie wystarczą.

Zmieniaj punkt załamania, gamma, punkt czerni i punkt bieli, obserwując krzywą.

Zapisz do pięciu nazwanych ustawień wstępnych. Ustawienia są przechowywane osobno dla każdego ekranu.

macOS 2.6

Instalacja na Macu

  1. Pobierz i otwórz DMG.
  2. Przeciągnij E‑Ink Assistant do folderu Aplikacje.
  3. Spróbuj raz otworzyć aplikację. Jeśli macOS ją zablokuje, otwórz Ustawienia systemowe → Prywatność & ochrona i wybierz Otwórz mimo to.

To niezależnie rozwijane oprogramowanie, które obecnie nie jest dostępne w App Store. Przy pierwszym otwarciu macOS wyświetli ostrzeżenie o braku możliwości weryfikacji. Kod jest w pełni otwarty, więc możesz go przejrzeć przed podjęciem decyzji o użyciu aplikacji.

Jeśli opcja „Otwórz mimo to” się nie pojawia

Po przeniesieniu aplikacji do folderu Aplikacje otwórz Terminal i uruchom:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Instalacja w Windows

  1. Pobierz i uruchom plik instalacyjny Setup.
  2. Zatwierdź prośbę o uprawnienia administratora.
  3. Otwórz E‑Ink Assistant z menu Start lub zasobnika systemowego.

Dla systemów od Windows 7 SP1 do Windows 11 na komputerach x64. Dostępne ustawienia zależą od wersji Windows, karty graficznej, sterownika i połączenia ekranu.
