01 / QARI

Agħmel test ċar wisq aktar skur

  • Kuntrast tat-test joffri erba' livelli għal paġni b'kuntrast baxx.
  • Użah għall-qari; huwa separat minn Titjib tal-vidjo.

02 / RITRATTI + VIDJO

Ikxef dettalji mudlama

  • Titjib tal-vidjo idawwal id-dettalji fid-dellijiet fir-ritratti u l-vidjo.
  • Itfih għall-qari għax idawwal ukoll it-test skur.

03 / E-INK BIL-KULUR

Aġġusta s-saturazzjoni u RGB

  • Uża presets jew kontrolli diretti biex tikkumpensa għal firxa limitata tal-kuluri.
  • Id-disponibbiltà tiddependi mis-sistema operattiva, il-GPU, id-driver, u l-mogħdija tal-konnessjoni tal-iskrin.

04 / GĦAL KULL SKRIN

Żomm settings għal kull pannell

  • Immarka biss l-iskrins e-ink li trid li l-app tibdel.
  • Issejvja kurvi għal skrins differenti u rrestawra s-settings meta tagħlaq l-app.

03 / IRFINAR FAKULTATTIV

meta l-presets ma jkunux biżżejjed.

macOS 2.6

Installa fuq Mac

  1. Niżżel u iftaħ id-DMG.
  2. Iġbed E‑Ink Assistant għal Applications.
  3. Ipprova iftaħ l-app darba. Jekk macOS jimblokkaha, iftaħ Settings tas-Sistema → Privatezza & Sigurtà u agħżel Iftaħ Xorta Waħda.

Dan huwa software żviluppat indipendentement u bħalissa mhuwiex fuq l-App Store. macOS juri twissija li “ma jistax jiġi vverifikat” l-ewwel darba li tiftaħha. Il-kodiċi huwa kompletament miftuħ, għalhekk tista' tirrevedih qabel tiddeċiedi jekk tużahx.

Jekk “Iftaħ Xorta Waħda” ma jidhirx

Wara li tmexxi l-app għal Applications, iftaħ Terminal u ħaddem:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Installa fuq Windows

  1. Niżżel u ħaddem il-fajl Setup.
  2. Approva t-talba għall-permess ta' amministratur.
  3. Iftaħ E‑Ink Assistant mill-menu Start jew miż-żona tan-notifiki.

Għal Windows 7 SP1 sa Windows 11 fuq kompjuters x64. Il-kontrolli disponibbli jiddependu mill-verżjoni ta' Windows, il-GPU, id-driver, u l-konnessjoni tal-iskrin.
