01 / CO OVLÁDÁNÍ DĚLAJÍ

Vyberte ovládání
podle obsahu.

Kontrast textu ztmaví stránky pro čtení. Vylepšení videa odhalí detaily v tmavých obrázcích. Sytost a RGB pomáhají barevným e-ink panelům.

Ilustrační náhledy. Výsledky se liší podle panelu a zdrojového materiálu.

02 / PODROBNOSTI FUNKCÍ

MAC A WINDOWS

Společná ovládání.
Omezení podle systému.

Aplikace využívá veřejná ovládání displeje dostupná v jednotlivých operačních systémech. Nepodporovaná ovládání jsou skrytá nebo vysvětlená.

OBOJÍ
Kontrast textu, Vylepšení videa, křivky, předvolby a nastavení pro jednotlivé displeje.
POUZE macOS
Omezit chvění a nastavení Night Shift / True Tone pro jednotlivé displeje.
BARVY VE WINDOWS
Vhodné systémy Windows 10 2004 a Windows 11 21H2+; dostupnost závisí na systému a hardwaru.

01 / ČTENÍ

Ztmavte slabý text

  • Kontrast textu nabízí čtyři úrovně pro stránky s nízkým kontrastem.
  • Používejte ho pro čtení; je oddělený od Vylepšení videa.

02 / FOTOGRAFIE + VIDEO

Odhalte tmavé detaily

  • Vylepšení videa zvýrazní detaily ve stínech fotografií a videa.
  • Při čtení ho vypněte, protože zesvětluje i tmavý text.

03 / BAREVNÝ E-INK

Upravte sytost a RGB

  • Pomocí předvoleb nebo přímého ovládání kompenzujte omezený barevný gamut.
  • Dostupnost závisí na operačním systému, GPU, ovladači a způsobu připojení displeje.

04 / PRO KAŽDÝ DISPLEJ

Uchovejte nastavení pro každý panel

  • Označte pouze e-ink displeje, které má aplikace upravovat.
  • Uložte křivky pro různé displeje a při ukončení aplikace obnovte původní nastavení.

03 / VOLITELNÉ JEMNÉ DOLADĚNÍ

Upravte křivku,
když předvolby nestačí.

Při sledování křivky měňte bod zlomu, Gamma, černý bod a bílý bod.

Uložte až pět pojmenovaných předvoleb. Nastavení se ukládají samostatně pro každý displej.

macOS 2.6

Instalace na Mac

  1. Stáhněte a otevřete DMG.
  2. Přetáhněte E‑Ink Assistant do složky Aplikace.
  3. Zkuste aplikaci jednou otevřít. Pokud ji macOS zablokuje, otevřete Nastavení systému → Soukromí & zabezpečení a vyberte Přesto otevřít.

Jde o nezávisle vyvíjený software, který zatím není v App Storu. macOS při prvním otevření zobrazí upozornění, že jej nelze ověřit. Kód je plně otevřený, takže si ho můžete prohlédnout, než se rozhodnete aplikaci používat.

Pokud se možnost „Přesto otevřít“ nezobrazí

Po přesunutí aplikace do složky Aplikace otevřete Terminál a spusťte:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Instalace ve Windows

  1. Stáhněte a spusťte instalační soubor.
  2. Potvrďte výzvu k oprávnění správce.
  3. Otevřete E‑Ink Assistant z nabídky Start nebo oznamovací oblasti.

Pro Windows 7 SP1 až Windows 11 na počítačích x64. Dostupná ovládání závisí na verzi Windows, GPU, ovladači a připojení displeje.
