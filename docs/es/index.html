01 / QUÉ HACEN LOS CONTROLES

Elige el control
según el contenido.

Contraste del texto oscurece las páginas de lectura. Mejora de vídeo revela los detalles oscuros de las imágenes. Saturación y RGB ayudan a los paneles de tinta electrónica en color.

Vistas previas ilustrativas. Los resultados varían según el panel y el contenido original.

01 / LECTURA

Oscurece el texto tenue

  • Contraste del texto ofrece cuatro niveles para páginas de bajo contraste.
  • Úsalo para leer; es independiente de Mejora de vídeo.

02 / FOTOS + VÍDEO

Revela los detalles oscuros

  • Mejora de vídeo aclara el detalle en las sombras de fotos y vídeos.
  • Desactívala para leer, ya que también aclara el texto oscuro.

03 / TINTA ELECTRÓNICA EN COLOR

Ajusta la saturación y RGB

  • Usa ajustes predefinidos o controles directos para compensar una gama de colores limitada.
  • La disponibilidad depende del sistema operativo, la GPU, el controlador y la ruta de salida a la pantalla.

04 / POR PANTALLA

Conserva los ajustes de cada panel

  • Marca solo las pantallas de tinta electrónica que quieras que modifique la app.
  • Guarda curvas para distintas pantallas y restaura los ajustes al salir de la app.

03 / AJUSTE FINO OPCIONAL

Ajusta la curva
cuando los valores predefinidos no basten.

Cambia el punto de transición, gamma, punto negro y punto blanco mientras observas la curva.

Guarda hasta cinco ajustes predefinidos con nombre. La configuración se almacena por separado para cada pantalla.

macOS 2.6

Instalar en Mac

  1. Descarga y abre el DMG.
  2. Arrastra E‑Ink Assistant a Aplicaciones.
  3. Intenta abrir la app una vez. Si macOS la bloquea, abre Ajustes del Sistema → Privacidad & seguridad y selecciona Abrir igualmente.

Este software se desarrolla de forma independiente y actualmente no está en el App Store. macOS mostrará un aviso de que no puede verificarlo la primera vez que lo abras. Todo el código es abierto, así que puedes revisarlo antes de decidir si lo usas.

Si no aparece «Abrir igualmente»

Después de mover la app a Aplicaciones, abre Terminal y ejecuta:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Instalar en Windows

  1. Descarga y ejecuta el archivo de instalación.
  2. Acepta la solicitud de permisos de administrador.
  3. Abre E‑Ink Assistant desde el menú Inicio o la bandeja del sistema.

Para equipos x64 desde Windows 7 SP1 hasta Windows 11. Los controles disponibles dependen de la versión de Windows, la GPU, el controlador y la conexión de pantalla.
