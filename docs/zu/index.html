01 / LOKHO OKWENZIWA IZILAWULI

Khetha isilawuli
esifanele okuqukethwe.

Ukugqama Kombhalo kwenza amakhasi okufunda abe mnyama. Ukuthuthukisa Ividiyo kuveza imininingwane yezithombe ezimnyama. Ukugcwala Kombala ne-RGB kusiza amaphaneli e-e-ink anemibala.

Ukubuka kuqala okuyizibonelo. Imiphumela iyahlukahluka ngephaneli nangokuqukethwe kokuqala.

02 / IMINININGWANE YEZICI

I-MAC NE-WINDOWS

Izilawuli ezifanayo.
Imikhawulo yesistimu ngayinye.

Uhlelo lusebenzisa izilawuli zomphakathi zesibonisi ezitholakala kusistimu ngayinye yokusebenza. Izilawuli ezingasekelwa ziyafihlwa noma zichazwe.

01 / UKUFUNDA

Yenza umbhalo ofiphele ube mnyama

  • Ukugqama Kombhalo kunikeza amazinga amane amakhasi anokugqama okuphansi.
  • Kusebenzise uma ufunda; kuhlukile ekuThuthukiseni Ividiyo.

02 / IZITHOMBE + IVIDIYO

Veza imininingwane emnyama

  • Ukuthuthukisa Ividiyo kukhanyisa imininingwane yezithunzi ezithombeni nakumavidiyo.
  • Kuvale uma ufunda ngoba kukhanyisa nombhalo omnyama.

03 / I-E-INK ENEMIBALA

Lungisa ukugcwala kombala ne-RGB

  • Sebenzisa okusethiwe noma izilawuli eziqondile ukuze unxephezele uhla lwemibala olulinganiselwe.
  • Ukutholakala kuncike kusistimu yokusebenza, ku-GPU, kumshayeli nasendleleni yokuxhumeka kwesibonisi.

04 / ISIBONISI NGASINYE

Gcina izilungiselelo zephaneli ngayinye

  • Maka kuphela izibonisi ze-e-ink ofuna uhlelo luzishintshe.
  • Londoloza amajika ezibonisi ezihlukene, bese ubuyisela izilungiselelo zokuqala uma uphuma ohlelweni.

03 / UKULUNGISA NGOKUCOPHELELA ONGAKUKHETHA

Lungisa ijika
uma okusethiwe kunganele.

Shintsha iphuzu lokugoba, i-gamma, iphuzu elimnyama nephuzu elimhlophe ubuka ijika.

Londoloza okusethiwe okuqanjwe amagama okufika kokuhlanu. Izilungiselelo zigcinwa ngokwehlukana ngesibonisi ngasinye.

macOS 2.6

Faka ku-Mac

  1. Landa bese uvula i-DMG.
  2. Hudulela i-E‑Ink Assistant ku-Izinhlelo Zokusebenza.
  3. Zama ukuvula uhlelo kanye. Uma i-macOS iluvimba, vula Izilungiselelo Zesistimu → Ubumfihlo & Ukuphepha bese ukhetha Vula Noma Kunjalo.

Le softhiwe ithuthukiswe ngokuzimela futhi okwamanje ayikho ku-App Store. I-macOS izobonisa isexwayiso esithi “ayikwazi ukuqinisekisa” uma uyivula okokuqala. Ikhodi ivulekile ngokuphelele, ngakho ungayihlola ngaphambi kokunquma ukuthi uyayisebenzisa yini.

Uma “Vula Noma Kunjalo” kungaveli

Ngemva kokuhambisa uhlelo ku-Izinhlelo Zokusebenza, vula i-Terminal bese usebenzisa:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Faka ku-Windows

  1. Landa bese usebenzisa ifayela lokufaka.
  2. Vumela isicelo somlawuli.
  3. Vula i-E‑Ink Assistant kumenyu ethi Qala noma kuthreyi yesistimu.

Nge-Windows 7 SP1 kuya ku-Windows 11 kumakhompyutha e-x64. Izilawuli ezitholakalayo zincike enguqulweni ye-Windows, ku-GPU, kumshayeli nasekuxhumekeni kwesibonisi.
