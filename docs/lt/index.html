01 / KĄ DARO VALDIKLIAI

Pasirinkite valdiklį
pagal turinį.

Teksto kontrastas patamsina skaitomus puslapius. Vaizdo gerinimas atskleidžia tamsias vaizdo detales. Sodrumas ir RGB padeda spalvoto elektroninio rašalo ekranams.

Iliustracinės peržiūros. Rezultatai priklauso nuo ekrano ir pradinės medžiagos.

02 / FUNKCIJŲ INFORMACIJA

MAC IR WINDOWS

Bendri valdikliai.
Kiekvienos sistemos ribojimai.

Programa naudoja viešus ekrano valdiklius, prieinamus kiekvienoje operacinėje sistemoje. Nepalaikomi valdikliai paslepiami arba paaiškinami.

ABI

01 / SKAITYMAS

Patamsinkite blyškų tekstą

  • Teksto kontrastas siūlo keturis lygius mažo kontrasto puslapiams.
  • Naudokite skaitymui; jis atskiras nuo Vaizdo gerinimo.

02 / NUOTRAUKOS + VAIZDO ĮRAŠAI

Atskleiskite tamsias detales

  • Vaizdo gerinimas pašviesina nuotraukų ir vaizdo įrašų šešėlių detales.
  • Skaitant išjunkite, nes jis šviesina ir tamsų tekstą.

03 / SPALVOTAS ELEKTRONINIS RAŠALAS

Derinkite sodrumą ir RGB

  • Naudokite išankstines nuostatas arba tiesioginius valdiklius ribotai spalvų gamai kompensuoti.
  • Prieinamumas priklauso nuo operacinės sistemos, GPU, tvarkyklės ir ekrano kelio.

04 / KIEKVIENAM EKRANUI

Išsaugokite kiekvieno ekrano nuostatas

  • Pažymėkite tik tuos elektroninio rašalo ekranus, kuriuos norite keisti programa.
  • Išsaugokite kreives skirtingiems ekranams ir atkurkite nuostatas išeidami iš programos.

03 / PASIRENKAMAS TIKSLUS DERINIMAS

Derinkite kreivę,
kai išankstinių nuostatų nepakanka.

Keiskite lenkimo tašką, Gamma, juodąjį ir baltąjį taškus stebėdami kreivę.

Išsaugokite iki penkių išankstinių nuostatų su pavadinimais. Nuostatos saugomos atskirai kiekvienam ekranui.

macOS 2.6

Diegimas Mac kompiuteryje

  1. Atsisiųskite ir atverkite DMG.
  2. Nuvilkite E‑Ink Assistant į Applications.
  3. Vieną kartą pabandykite atverti programą. Jei macOS ją blokuoja, atverkite Sistemos nuostatos → Privatumas & sauga ir pasirinkite Vis tiek atverti.

Tai nepriklausomai sukurta programinė įranga, kurios šiuo metu nėra App Store. Pirmą kartą atveriant macOS parodys įspėjimą, kad jos nepavyksta patikrinti. Visas kodas yra atviras, todėl galite jį peržiūrėti prieš nuspręsdami, ar naudoti programą.

Jei parinktis „Vis tiek atverti“ nerodoma

Perkėlę programą į Applications, atverkite Terminal ir vykdykite:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"
Atsisiųsti macOS 2.6 ↓Jei naudinga, skirkite projektui žvaigždutę GitHub ↗

WINDOWS 1.2

Diegimas Windows sistemoje

  1. Atsisiųskite ir paleiskite diegimo failą.
  2. Patvirtinkite administratoriaus teisių užklausą.
  3. Atverkite E‑Ink Assistant iš pradžios meniu arba sistemos dėklo.

Skirta Windows 7 SP1–Windows 11 x64 kompiuteriams. Prieinami valdikliai priklauso nuo Windows versijos, GPU, tvarkyklės ir ekrano jungties.
