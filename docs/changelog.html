CHANGELOG

VERSION 2.6

SEPTEMBER 2, 2026

Improved mirrored-display support.

  • Hardware-mirrored secondary displays remain individually selectable and are tuned by physical output.
  • Switching between mirrored and extended layouts promptly refreshes and reapplies display settings.
  • Reapply and quit cleanup touch only marked e-ink panels while also covering online mirrored displays.
  • The setup tip now explicitly directs users to the monitor's own menu.

VERSION 2.5

SEPTEMBER 2, 2026

Added concise hardware setup guidance.

  • A dismissible reminder now appears above the controls, with a Bigme B251 Pro example.
  • Got it hides the reminder for the session; Never show it again persists after relaunch.
  • The welcome panel now uses three concise, icon-led setup points.
  • Built-in displays now appear after external displays in the selection list.

VERSION 2.4

SEPTEMBER 1, 2026

Panel height follows the current screen.

  • The control panel now uses the visible height of the screen containing the menu-bar item.
  • Tall content scrolls and leaves 40 points above the Dock or screen edge. Shorter panels keep their natural height.

VERSION 2.3

SEPTEMBER 1, 2026

Changed the Text Contrast preset values.

  • Medium uses the previous Strong curve. Strong, Sharp, and Solid are progressively darker.
  • Sharp uses gamma 5.00 with a 0.10 black point. Solid uses gamma 6.00 with a 0.34 black point. Both remove more gray detail and produce harder edges.

VERSION 2.2

AUGUST 14, 2026

Fixed language switching in How this works.

  • The section heading and Show more / Show less button now update immediately when the app language changes.

VERSION 2.1

AUGUST 14, 2026

Updated the settings helper.

  • The helper can run while the Mac is locked, preventing Shortcuts warnings during disconnect and cleanup.
  • Users upgrading from v2.0 must add the renamed helper once, then may remove the old helper.

VERSION 2.0

AUGUST 13, 2026

Added display controls, languages, and a DMG installer.

  • Added per-display RGB, Night Shift, and True Tone controls.
  • Added Reduce Transparency and Motion control through a user-confirmed Shortcuts helper.
  • Added English, Simplified Chinese, Traditional Chinese, and Japanese.

VERSION 1.1

Added per-display Night Shift and True Tone control.

  • The change requires an administrator password and a display reconnect. It is not undone when the app quits.

VERSION 1.0

Initial release.

  • Added Reduce Shaking, Saturation, Text Contrast, Video Enhance, custom tone curves, saved curve slots, and display restoration on quit.

VERSION 1.2

CURRENT

Improved color-control recovery.

  • Fixed false feature-failure warnings when Windows exposes a color pipeline but does not allow the app to change its state.
  • Recovery data is retained while Duplicate mode temporarily disables color control, then restored when a controllable display layout returns.

VERSION 1.1

Initial Windows release.

  • Added per-display Text Contrast, Video Enhance, advanced curves, presets, and e-ink display selection.
  • Added compatible Saturation, RGB, Windows Light Mode, and Night Light controls with restoration and crash recovery.
  • Added duplicate-display handling, system-tray onboarding, launch at login, updates, and a multilingual installer.
