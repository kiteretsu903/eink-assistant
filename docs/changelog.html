RELEASE HISTORY

What changed,
and when.

Updates to E‑Ink Assistant, from the latest version back to the first release.

VERSION 2.1

AUGUST 14, 2026

More reliable display automation.

  • Fixed the Shortcuts warning that could appear when display automation or cleanup ran while the Mac was locked.
  • Added a clearly named, locked-capable settings helper, so upgrades do not reuse the incompatible v2.0 helper.
  • Existing users confirm Add Shortcut once after upgrading. The previous helper can then be removed from Shortcuts.

VERSION 2.0

AUGUST 13, 2026

Color e‑ink, per-display controls, and a clearer interface.

  • Added direct per-display RGB controls and clearer guidance for both B&W and color e‑ink.
  • Added safe Reduce Transparency and Motion control through a user-confirmed Shortcuts helper.
  • Added per-display Night Shift and True Tone control, full English, Simplified Chinese, Traditional Chinese, and Japanese support, and a drag-to-Applications DMG installer.

VERSION 1.1

Per-display system color controls.

  • Added Night Shift and True Tone controls that apply only to the selected display.

VERSION 1.0

The first release.

  • Introduced per-display e‑ink tuning, including Reduce Shaking, Saturation, Text Contrast, Video Enhance, advanced tone curves, and saved presets.
