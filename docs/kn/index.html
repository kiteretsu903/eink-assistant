01 / ನಿಯಂತ್ರಣಗಳು ಏನು ಮಾಡುತ್ತವೆ

ನಿಯಂತ್ರಣ ಆಯ್ಕೆಮಾಡಿ.

ಪಠ್ಯದ ಕಾಂಟ್ರಾಸ್ಟ್ ಓದುವ ಪುಟಗಳನ್ನು ಗಾಢಗೊಳಿಸುತ್ತದೆ. ವೀಡಿಯೊ ಸುಧಾರಣೆ ಚಿತ್ರದ ಕತ್ತಲೆ ವಿವರಗಳನ್ನು ತೆರೆದಿಡುತ್ತದೆ. ಬಣ್ಣದ ಸಾಂದ್ರತೆ ಮತ್ತು RGB ಬಣ್ಣದ e‑ink ಪ್ಯಾನೆಲ್‌ಗಳಿಗೆ ನೆರವಾಗುತ್ತವೆ.

ವಿವರಣಾತ್ಮಕ ಪೂರ್ವವೀಕ್ಷಣೆಗಳು. ಫಲಿತಾಂಶಗಳು ಪ್ಯಾನೆಲ್ ಮತ್ತು ಮೂಲ ವಿಷಯಕ್ಕೆ ಅನುಗುಣವಾಗಿ ಬದಲಾಗುತ್ತವೆ.
