01 / KONTROLEK ZER EGITEN DUTEN

Aukeratu kontrola
edukiaren arabera.

Testuaren kontrasteak irakurtzeko orriak iluntzen ditu. Irudia hobetu aukerak irudiko xehetasun ilunak erakusten ditu. Saturazioak eta RGBk koloretako e‑ink pantailei laguntzen diete.

Azalpenezko aurrebistak. Emaitzak pantailaren eta jatorrizko materialaren arabera aldatzen dira.

02 / EZAUGARRIEN XEHETASUNAK

MAC ETA WINDOWS

Kontrol partekatuak.
Sistema bakoitzaren mugak.

Aplikazioak sistema eragile bakoitzean erabilgarri dauden pantaila-kontrol publikoak erabiltzen ditu. Onartzen ez diren kontrolak ezkutatu edo azaldu egiten dira.

BIETAN
Testuaren kontrastea, Irudia hobetu, kurbak, aurrezarpenak eta pantaila bakoitzeko ezarpenak.
macOS SOILIK
Dardara murriztea eta pantaila bakoitzeko Night Shift / True Tone kudeaketa.
KOLOREA WINDOWS-EN
Windows 10 2004 eta Windows 11 21H2+ sistema bateragarriak; erabilgarritasuna sistemaren eta hardwarearen araberakoa da.

01 / IRAKURKETA

Ilundu testu lausoa

  • Testuaren kontrasteak lau maila eskaintzen ditu kontraste txikiko orrietarako.
  • Erabili irakurtzeko; Irudia hobetu aukeratik bereizita dago.

02 / ARGAZKIAK + BIDEOA

Erakutsi xehetasun ilunak

  • Irudia hobetu aukerak argazki eta bideoetako itzalen xehetasunak argitzen ditu.
  • Desaktibatu irakurtzeko, testu iluna ere argitzen baitu.

03 / KOLORETAKO E‑INK

Doitu saturazioa eta RGB

  • Erabili aurrezarpenak edo zuzeneko kontrolak kolore-gama mugatua konpentsatzeko.
  • Erabilgarritasuna sistema eragilearen, GPUaren, kontrolatzailearen eta pantaila-bidearen araberakoa da.

04 / PANTAILA BAKOITZEKO

Mantendu ezarpenak pantaila bakoitzarekin

  • Markatu aplikazioak aldatu behar dituen e‑ink pantailak soilik.
  • Gorde kurbak pantaila desberdinetarako eta leheneratu ezarpenak aplikaziotik irtetean.

03 / AUKERAKO DOIKUNTZA ZEHATZA

Doitu kurba
aurrezarpenak nahikoak ez direnean.

Aldatu tolestura-puntua, gamma, puntu beltza eta puntu zuria kurba ikusten duzun bitartean.

Gorde bost aurrezarpen izendatu gehienez. Ezarpenak pantaila bakoitzerako bereizita gordetzen dira.

macOS 2.6

Instalatu Mac-en

  1. Deskargatu eta ireki DMGa.
  2. Arrastatu E‑Ink Assistant Applications karpetara.
  3. Saiatu aplikazioa behin irekitzen. macOSek blokeatzen badu, ireki Sistemaren ezarpenak → Pribatutasuna eta segurtasuna eta hautatu Ireki hala ere.

Modu independentean garatutako softwarea da eta une honetan ez dago App Store-n. macOSek egiaztatu ezin dela dioen abisua erakutsiko du lehen aldiz irekitzean. Kode guztia irekia da; beraz, azter dezakezu erabili nahi duzun erabaki aurretik.

«Ireki hala ere» agertzen ez bada

Aplikazioa Applications karpetara mugitu ondoren, ireki Terminal eta exekutatu:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Instalatu Windows-en

  1. Deskargatu eta exekutatu instalazio-fitxategia.
  2. Onartu administratzailearen baimen-eskaera.
  3. Ireki E‑Ink Assistant Hasi menutik edo sistemaren erretilutik.

Windows 7 SP1etik Windows 11ra, x64 ordenagailuetan. Kontrol erabilgarriak Windows-en bertsioaren, GPUaren, kontrolatzailearen eta pantailaren konexioaren araberakoak dira.
