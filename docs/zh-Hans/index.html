01 / 阅读

让浅色文字更深

  • 文字对比度为低对比度页面提供四个级别。
  • 适合阅读时使用；与视频暗部增强分开设置。

02 / 照片 + 视频

呈现暗部细节

  • 视频暗部增强提亮照片和视频中的阴影细节。
  • 阅读时请关闭，因为它也会让深色文字变浅。

03 / 彩色墨水屏

调节饱和度与 RGB

  • 使用预设或直接调节，补偿有限的色域。
  • 可用性取决于操作系统、GPU、驱动程序和显示连接路径。

04 / 按显示器设置

为每块面板保留设置

  • 只标记希望由应用调节的墨水屏。
  • 为不同显示器保存曲线，退出应用时恢复设置。

03 / 可选微调

预设不够用时
亲自调节曲线。

一边查看曲线，一边调节拐点、伽马、黑点和白点。

最多可保存五个命名预设。每台显示器的设置单独保存。

macOS 2.6

在 Mac 上安装

  1. 下载并打开 DMG。
  2. 将 E‑Ink Assistant 拖入应用程序。
  3. 先尝试打开应用一次。如果 macOS 阻止打开，请前往系统设置 → 隐私与安全性，选择仍要打开。

这是独立开发的软件，目前尚未上架 App Store。macOS 会在首次打开时显示“无法验证”警告。代码完全开源，你可以先审阅，再决定是否使用。

如果没有出现“仍要打开”

将应用移入“应用程序”后，打开终端并运行：

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"
