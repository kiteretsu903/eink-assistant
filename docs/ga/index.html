01 / CAD A DHÉANANN NA RIALTÁIN

Roghnaigh an rialtán
don ábhar.

Dorchaíonn Codarsnacht Téacs leathanaigh léitheoireachta. Nochtann Feabhsú Físeáin sonraí dorcha íomhá. Cabhraíonn Sáithiú agus RGB le painéil e‑ink daite.

Réamhamhairc léiritheacha. Athraíonn na torthaí de réir an phainéil agus an bhunábhair.

01 / LÉITHEOIREACHT

Déan téacs fann níos dorcha

  • Tairgeann Codarsnacht Téacs ceithre leibhéal do leathanaigh ísealchodarsnachta.
  • Úsáid le haghaidh léitheoireachta é; tá sé ar leith ó Fheabhsú Físeáin.

02 / GRIANGHRAIF + FÍSEÁIN

Nocht sonraí dorcha

  • Soilsíonn Feabhsú Físeáin sonraí sna scáthanna i ngrianghraif agus i bhfíseáin.
  • Múch é le haghaidh léitheoireachta mar go soilsíonn sé téacs dorcha freisin.

03 / E‑INK DAITE

Coigeartaigh sáithiú agus RGB

  • Úsáid réamhshocruithe nó rialtáin dhíreacha chun raon teoranta dathanna a chúiteamh.
  • Braitheann infhaighteacht ar an gcóras oibriúcháin, GPU, tiománaí agus nasc an scáileáin.

04 / IN AGHAIDH AN SCÁILEÁIN

Coinnigh socruithe le gach painéal

  • Ná marcáil ach na scáileáin e‑ink is mian leat a athrú leis an aip.
  • Sábháil cuair do scáileáin éagsúla agus athchóirigh socruithe nuair a scoireann an aip.

03 / MIONCHOIGEARTÚ ROGHNACH

Coigeartaigh an cuar
nuair nach leor na réamhshocruithe.

Athraigh an pointe lúibe, gáma, pointe dubh agus pointe bán agus tú ag féachaint ar an gcuar.

Sábháil suas le cúig réamhshocrú ainmnithe. Stóráiltear socruithe ar leith do gach scáileán.

ÍOSLÓDÁIL

Cuir do scáileán e‑ink
in oiriúint duit féin.

Tá an dá leagan saor in aisce agus foinse oscailte.

macOS 2.6↓Windows 1.2↓

macOS 14+ Apple Silicon · Windows 7 SP1–11 x64

macOS 2.6

Suiteáil ar Mac

  1. Íoslódáil agus oscail an DMG.
  2. Tarraing E‑Ink Assistant isteach in Feidhmchláir.
  3. Déan iarracht an aip a oscailt uair amháin. Má chuireann macOS bac uirthi, oscail Socruithe Córais → Príobháideachas & Slándáil agus roghnaigh Oscail Mar Sin Féin.

Is bogearraí neamhspleácha iad seo agus níl siad san App Store faoi láthair. Taispeánfaidh macOS rabhadh nach féidir iad a fhíorú nuair a osclaíonn tú iad den chéad uair. Tá an cód go hiomlán foinse oscailte, ionas gur féidir leat é a scrúdú sula gcinnfidh tú é a úsáid.

Mura bhfuil “Oscail Mar Sin Féin” le feiceáil

Tar éis duit an aip a bhogadh go Feidhmchláir, oscail Terminal agus rith:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"
Íoslódáil macOS 2.6 ↓Má chuidíonn sé leat, tabhair réalta don tionscadal ar GitHub ↗

WINDOWS 1.2

Suiteáil ar Windows

  1. Íoslódáil agus rith an comhad suiteála.
  2. Ceadaigh an t-iarratas riarthóra.
  3. Oscail E‑Ink Assistant ón roghchlár Tosaigh nó ón tráidire córais.

Le haghaidh Windows 7 SP1 go Windows 11 ar ríomhairí x64. Braitheann na rialtáin atá ar fáil ar leagan Windows, GPU, tiománaí agus nasc an scáileáin.
