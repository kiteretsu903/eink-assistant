01 / O QUE OS CONTROLES FAZEM

Escolha o controle
para o conteúdo.

Contraste do texto escurece as páginas de leitura. Melhoria de vídeo revela detalhes escuros nas imagens. Saturação e RGB ajudam os painéis e‑ink coloridos.

Prévias ilustrativas. Os resultados variam conforme o painel e o material de origem.

02 / DETALHES DOS RECURSOS

MAC VS WINDOWS

Controles compartilhados.
Limitações de cada sistema.

O app usa os controles públicos de monitor disponíveis em cada sistema operacional. Os controles sem suporte são ocultados ou explicados.

AMBOS
Contraste do texto, Melhoria de vídeo, curvas, predefinições e ajustes por monitor.

COR NO WINDOWS

01 / LEITURA

Escureça textos claros

  • Contraste do texto oferece quatro níveis para páginas com baixo contraste.
  • Use para leitura; é independente de Melhoria de vídeo.

02 / FOTOS + VÍDEOS

Revele detalhes escuros

  • Melhoria de vídeo realça os detalhes nas sombras de fotos e vídeos.
  • Desative para leitura, pois também clareia o texto escuro.

03 / E‑INK COLORIDO

Ajuste a saturação e o RGB

  • Use predefinições ou controles diretos para compensar uma gama de cores limitada.
  • A disponibilidade depende do sistema operacional, da GPU, do driver e do caminho de saída do monitor.

04 / POR MONITOR

Mantenha os ajustes de cada painel

  • Marque apenas os monitores e‑ink que você deseja alterar com o app.
  • Salve curvas para diferentes monitores e restaure os ajustes ao sair do app.

03 / AJUSTE FINO OPCIONAL

Ajuste a curva
quando as predefinições não bastarem.

Altere o ponto de transição, Gamma, ponto preto e ponto branco enquanto visualiza a curva.

Salve até cinco predefinições nomeadas. Os ajustes são armazenados separadamente para cada monitor.

macOS 2.6

Instalar no Mac

  1. Baixe e abra o DMG.
  2. Arraste E‑Ink Assistant para Aplicativos.
  3. Tente abrir o app uma vez. Se o macOS bloquear, abra Ajustes do Sistema → Privacidade & Segurança e selecione Abrir Mesmo Assim.

Este software é desenvolvido de forma independente e atualmente não está na App Store. O macOS mostrará um aviso de que “não é possível verificar” na primeira vez que você abri-lo. O código é totalmente aberto, então você pode analisá-lo antes de decidir se deseja usá-lo.

Se “Abrir Mesmo Assim” não aparecer

Depois de mover o app para Aplicativos, abra o Terminal e execute:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Instalar no Windows

  1. Baixe e execute o arquivo de instalação.
  2. Aprove a solicitação de administrador.
  3. Abra o E‑Ink Assistant pelo menu Iniciar ou pela bandeja do sistema.

Para Windows 7 SP1 ao Windows 11 em computadores x64. Os controles disponíveis dependem da versão do Windows, da GPU, do driver e da conexão do monitor.
