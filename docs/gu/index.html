તમારા કામ પ્રમાણે.

તમે પસંદ કરેલા ઈ-ઇન્ક ડિસ્પ્લે પર ટેક્સ્ટ કોન્ટ્રાસ્ટ, પડછાયાની વિગતો અને રંગ ગોઠવો. તમારા અન્ય ડિસ્પ્લે યથાવત્ રહે છે.

01 / નિયંત્રણો શું કરે છે

નિયંત્રણ પસંદ કરો
સામગ્રી પ્રમાણે.

ટેક્સ્ટ કોન્ટ્રાસ્ટ વાંચનનાં પાનાં ઘાટાં કરે છે. વિડિયો સુધારણા ચિત્રની ઘેરી વિગતો દેખાડે છે. રંગની સંતૃપ્તિ અને RGB રંગીન ઈ-ઇન્ક સ્ક્રીનને મદદ કરે છે.

સમજ માટેના પૂર્વાવલોકન. પરિણામ સ્ક્રીન અને મૂળ સામગ્રી પ્રમાણે બદલાય છે.

02 / સુવિધાઓની વિગતો

MAC અને WINDOWS

સમાન નિયંત્રણો.
સિસ્ટમ પ્રમાણે મર્યાદાઓ.

ઍપ દરેક ઑપરેટિંગ સિસ્ટમમાં ઉપલબ્ધ જાહેર ડિસ્પ્લે નિયંત્રણો વાપરે છે. સમર્થિત ન હોય તેવા નિયંત્રણો છુપાવવામાં આવે છે અથવા તેનું કારણ સમજાવવામાં આવે છે.

બંને
ટેક્સ્ટ કોન્ટ્રાસ્ટ, વિડિયો સુધારણા, વક્રો, પ્રીસેટ અને દરેક ડિસ્પ્લેની સેટિંગ્સ.
ફક્ત macOS
ઝબૂકવું ઘટાડો અને દરેક ડિસ્પ્લે માટે Night Shift / True Tone વ્યવસ્થાપન.
WINDOWS રંગ
લાગુ પડતી Windows 10 2004 અને Windows 11 21H2+ સિસ્ટમ્સ; ઉપલબ્ધતા સિસ્ટમ અને હાર્ડવેર પર આધારિત છે.

01 / વાંચન

ઝાંખું લખાણ ઘાટું કરો

  • ટેક્સ્ટ કોન્ટ્રાસ્ટ ઓછા કોન્ટ્રાસ્ટવાળાં પાનાં માટે ચાર સ્તર આપે છે.
  • વાંચન માટે વાપરો; તે વિડિયો સુધારણાથી અલગ છે.

02 / ફોટા + વિડિયો

ઘેરી વિગતો દેખાડો

  • વિડિયો સુધારણા ફોટા અને વિડિયોમાં પડછાયાની વિગતો ઉજળી કરે છે.
  • વાંચન માટે બંધ કરો, કારણ કે તે ઘેરું લખાણ પણ હળવું કરે છે.

03 / રંગીન ઈ-ઇન્ક

રંગની સંતૃપ્તિ અને RGB ગોઠવો

  • મર્યાદિત રંગવ્યાપની ભરપાઈ કરવા પ્રીસેટ અથવા સીધા નિયંત્રણો વાપરો.
  • ઉપલબ્ધતા ઑપરેટિંગ સિસ્ટમ, GPU, ડ્રાઇવર અને ડિસ્પ્લે માર્ગ પર આધારિત છે.

04 / દરેક ડિસ્પ્લે માટે

દરેક સ્ક્રીનની સેટિંગ્સ રાખો

  • ઍપથી બદલવા માંગતા હો ફક્ત તે ઈ-ઇન્ક ડિસ્પ્લે ચિહ્નિત કરો.
  • અલગ ડિસ્પ્લે માટે વક્રો સાચવો અને ઍપ બંધ થતાં સેટિંગ્સ પુનઃસ્થાપિત કરો.

03 / વૈકલ્પિક સૂક્ષ્મ ગોઠવણ

વક્ર ગોઠવો
જ્યારે પ્રીસેટ પૂરતા ન હોય.

વક્ર જોતા-જોતા વળાંક બિંદુ, Gamma, બ્લૅક પૉઇન્ટ અને વ્હાઇટ પૉઇન્ટ બદલો.

નામ આપેલા પાંચ જેટલા પ્રીસેટ સાચવો. દરેક ડિસ્પ્લેની સેટિંગ્સ અલગ સંગ્રહાય છે.
