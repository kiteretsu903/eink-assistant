01 / WAS DIE REGLER BEWIRKEN

Wählen Sie die Anpassung
passend zum Inhalt.

Textkontrast dunkelt Leseseiten ab. Videoverbesserung macht dunkle Bilddetails sichtbar. Sättigung und RGB helfen Farb-E‑Ink-Displays.

Veranschaulichende Vorschauen. Ergebnisse variieren je nach Display und Ausgangsmaterial.

02 / FUNKTIONEN IM DETAIL

MAC UND WINDOWS

Gemeinsame Regler.
Systembedingte Grenzen.

Die App nutzt die öffentlichen Displaysteuerungen des jeweiligen Betriebssystems. Nicht unterstützte Regler werden ausgeblendet oder erläutert.

BEIDE
Textkontrast, Videoverbesserung, Kurven, Voreinstellungen und Einstellungen pro Display.
NUR macOS
Flimmern reduzieren und Night Shift / True Tone für einzelne Displays steuern.
WINDOWS-FARBEN
Geeignete Systeme mit Windows 10 2004 und Windows 11 21H2+; die Verfügbarkeit hängt von System und Hardware ab.

01 / LESEN

Schwachen Text dunkler machen

  • Textkontrast bietet vier Stufen für kontrastarme Seiten.
  • Verwenden Sie die Funktion zum Lesen; sie ist von der Videoverbesserung getrennt.

02 / FOTOS + VIDEO

Dunkle Details sichtbar machen

  • Videoverbesserung hellt Schattendetails in Fotos und Videos auf.
  • Schalten Sie sie zum Lesen aus, da sie auch dunklen Text aufhellt.

03 / FARB-E‑INK

Sättigung und RGB anpassen

  • Gleichen Sie einen begrenzten Farbumfang mit Voreinstellungen oder direkten Reglern aus.
  • Die Verfügbarkeit hängt von Betriebssystem, GPU, Treiber und Display-Anbindung ab.

04 / PRO DISPLAY

Einstellungen für jedes Display behalten

  • Markieren Sie nur die E‑Ink-Displays, die die App verändern soll.
  • Speichern Sie Kurven für verschiedene Displays und stellen Sie die Einstellungen beim Beenden der App wieder her.

03 / OPTIONALE FEINABSTIMMUNG

Passen Sie die Kurve an,
wenn Voreinstellungen nicht ausreichen.

Ändern Sie Knickpunkt, Gamma, Schwarzpunkt und Weißpunkt und verfolgen Sie dabei die Kurve.

Speichern Sie bis zu fünf benannte Voreinstellungen. Einstellungen werden für jedes Display separat gespeichert.

macOS 2.6

Auf dem Mac installieren

  1. Laden Sie die DMG-Datei herunter und öffnen Sie sie.
  2. Ziehen Sie E‑Ink Assistant in den Ordner Programme.
  3. Versuchen Sie einmal, die App zu öffnen. Wenn macOS sie blockiert, öffnen Sie Systemeinstellungen → Datenschutz & Sicherheit und wählen Sie Dennoch öffnen.

Diese Software wird unabhängig entwickelt und ist derzeit nicht im App Store erhältlich. macOS zeigt beim ersten Öffnen eine Warnung an, dass die App nicht überprüft werden kann. Der Code ist vollständig quelloffen, sodass Sie ihn prüfen können, bevor Sie sich für die Nutzung entscheiden.

Wenn „Dennoch öffnen“ nicht erscheint

Nachdem Sie die App in den Ordner Programme verschoben haben, öffnen Sie Terminal und führen Sie Folgendes aus:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Unter Windows installieren

  1. Laden Sie die Setup-Datei herunter und führen Sie sie aus.
  2. Bestätigen Sie die Administratorabfrage.
  3. Öffnen Sie E‑Ink Assistant über das Startmenü oder den Infobereich der Taskleiste.

Für Windows 7 SP1 bis Windows 11 auf x64-Computern. Verfügbare Regler hängen von Windows-Version, GPU, Treiber und Displayanschluss ab.
