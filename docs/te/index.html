01 / నియంత్రణలు ఏం చేస్తాయి

కంటెంట్‌కు సరిపోయే
నియంత్రణను ఎంచుకోండి.

వచన కాంట్రాస్ట్ చదివే పేజీలను ముదురు చేస్తుంది. వీడియో మెరుగుదల చీకటి చిత్ర వివరాలను చూపిస్తుంది. రంగు సంతృప్తత, RGB రంగుల ఇ-ఇంక్ ప్యానెల్‌లకు సహాయపడతాయి.

వివరణాత్మక ఉదాహరణలు. ఫలితాలు ప్యానెల్, మూల కంటెంట్‌పై ఆధారపడి ఉంటాయి.

02 / ఫీచర్ల వివరాలు

MAC, WINDOWS పోలిక

ఉమ్మడి నియంత్రణలు.
సిస్టమ్‌కు ప్రత్యేక పరిమితులు.

ప్రతి ఆపరేటింగ్ సిస్టమ్‌లో అందుబాటులో ఉన్న బహిరంగ డిస్‌ప్లే నియంత్రణలను యాప్ ఉపయోగిస్తుంది. మద్దతు లేని నియంత్రణలు దాచబడతాయి లేదా వివరణ ఇవ్వబడుతుంది.

రెండింటిలో
వచన కాంట్రాస్ట్, వీడియో మెరుగుదల, వక్రరేఖలు, ప్రీసెట్‌లు, డిస్‌ప్లే-వారీ సెట్టింగ్‌లు.
macOSలో మాత్రమే
మిణుకుమిణుకుల తగ్గింపు, డిస్‌ప్లే-వారీ Night Shift / True Tone నిర్వహణ.
WINDOWS రంగు
అనుకూల Windows 10 2004, Windows 11 21H2+ సిస్టమ్‌లు; లభ్యత సిస్టమ్, హార్డ్‌వేర్‌పై ఆధారపడి ఉంటుంది.

01 / చదవడం

పలుచని వచనాన్ని ముదురు చేయండి

  • వచన కాంట్రాస్ట్ తక్కువ కాంట్రాస్ట్ ఉన్న పేజీల కోసం నాలుగు స్థాయిలను అందిస్తుంది.
  • చదవడానికి వాడండి; ఇది వీడియో మెరుగుదల నుంచి వేరుగా ఉంటుంది.

02 / ఫోటోలు + వీడియో

చీకటి వివరాలను చూపండి

  • వీడియో మెరుగుదల ఫోటోలు, వీడియోల్లో నీడల వివరాలను ప్రకాశవంతం చేస్తుంది.
  • ముదురు వచనాన్ని కూడా పలుచబరుస్తుంది కాబట్టి చదివేటప్పుడు ఆఫ్ చేయండి.

03 / రంగుల ఇ-ఇంక్

రంగు సంతృప్తత, RGB సర్దుబాటు చేయండి

  • పరిమిత రంగు పరిధిని భర్తీ చేయడానికి ప్రీసెట్‌లు లేదా ప్రత్యక్ష నియంత్రణలను ఉపయోగించండి.
  • లభ్యత ఆపరేటింగ్ సిస్టమ్, GPU, డ్రైవర్, డిస్‌ప్లే మార్గంపై ఆధారపడి ఉంటుంది.

04 / ఒక్కో డిస్‌ప్లేకు

ప్రతి ప్యానెల్‌కు సెట్టింగ్‌లను నిలుపుకోండి

  • యాప్ మార్చాలని మీరు కోరుకునే ఇ-ఇంక్ డిస్‌ప్లేలను మాత్రమే గుర్తించండి.
  • వేర్వేరు డిస్‌ప్లేలకు వక్రరేఖలను సేవ్ చేసి, యాప్ నుంచి నిష్క్రమించినప్పుడు సెట్టింగ్‌లను పునరుద్ధరించండి.

03 / ఐచ్ఛిక సూక్ష్మ సర్దుబాటు

వక్రరేఖను సర్దుబాటు చేయండి
ప్రీసెట్‌లు సరిపోనప్పుడు.

వక్రరేఖను చూస్తూ మలుపు బిందువు, గామా, నలుపు బిందువు, తెలుపు బిందువును మార్చండి.

పేర్లతో ఐదు ప్రీసెట్‌ల వరకు సేవ్ చేయండి. ప్రతి డిస్‌ప్లేకు సెట్టింగ్‌లు వేరుగా నిల్వ చేయబడతాయి.
