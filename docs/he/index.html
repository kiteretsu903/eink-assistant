01 / מה הפקדים עושים

ניגודיות טקסט מכהה דפי קריאה. שיפור וידאו חושף פרטים כהים בתמונות. רוויה ו-RGB מסייעים למסכי דיו אלקטרוני צבעוניים.

01 / קריאה

הכהו טקסט חיוור

  • ניגודיות טקסט מציעה ארבע רמות לדפים בעלי ניגודיות נמוכה.
  • השתמשו בה לקריאה; היא נפרדת משיפור וידאו.

02 / תמונות + וידאו

חשפו פרטים כהים

  • שיפור וידאו מבהיר פרטים בצל בתמונות ובווידאו.
  • כבו אותו לצורך קריאה, מפני שהוא מבהיר גם טקסט כהה.

03 / דיו אלקטרוני צבעוני

התאימו רוויה ו-RGB

  • השתמשו בקביעות מוכנות או בפקדים ישירים כדי לפצות על מכלול צבעים מצומצם.
  • הזמינות תלויה במערכת ההפעלה, במעבד הגרפי, במנהל ההתקן ובמסלול התצוגה.

04 / לכל מסך

שמרו הגדרות לכל מסך

  • סמנו רק את מסכי הדיו האלקטרוני שברצונכם לשנות באמצעות היישום.
  • שמרו עקומות למסכים שונים ושחזרו את ההגדרות ביציאה מהיישום.

03 / כוונון נוסף לבחירה

התאימו את העקומה
כשהקביעות המוכנות אינן מספיקות.

שנו את נקודת הכיפוף, Gamma, הנקודה השחורה והנקודה הלבנה תוך צפייה בעקומה.

שמרו עד חמש קביעות מוכנות עם שמות. ההגדרות נשמרות בנפרד לכל מסך.

macOS 2.6

התקנה ב-Mac

  1. הורידו ופתחו את קובץ ה-DMG.
  2. גררו את E‑Ink Assistant אל יישומים.
  3. נסו לפתוח את היישום פעם אחת. אם macOS חוסם אותו, פתחו את הגדרות המערכת → פרטיות & אבטחה ובחרו פתיחה בכל זאת.

זו תוכנה שפותחה באופן עצמאי ואינה זמינה כעת ב-App Store. macOS יציג אזהרה שלא ניתן לאמת אותה בפתיחה הראשונה. הקוד פתוח במלואו, כך שתוכלו לעיין בו לפני שתחליטו אם להשתמש בה.

אם האפשרות ״פתיחה בכל זאת״ אינה מופיעה

לאחר העברת היישום אל ״יישומים״, פתחו את ״מסוף״ והריצו:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

התקנה ב-Windows

  1. הורידו והריצו את קובץ ההתקנה.
  2. אשרו את בקשת הרשאות מנהל המערכת.
  3. פתחו את E‑Ink Assistant מתפריט התחל או ממגש המערכת.

ל-Windows 7 SP1 עד Windows 11 במחשבי x64. הפקדים הזמינים תלויים בגרסת Windows, במעבד הגרפי, במנהל ההתקן ובחיבור המסך.
