01 / 調整機能の役割

表示する内容に
合った調整を。

テキストコントラストは読書ページの文字を濃くし、映像の暗部補正は画像の暗い部分を見やすくします。彩度と RGB はカラー電子ペーパーの色を補正します。

これらは効果を示すイメージです。結果はパネルと表示内容によって異なります。

02 / 機能の詳細

MAC と WINDOWS

共通の調整機能。
OS ごとに異なる制約。

各 OS で利用できる公開のディスプレイ制御機能を使用します。非対応の機能は非表示にするか、その理由を説明します。

両方
テキストコントラスト、映像の暗部補正、カーブ、プリセット、ディスプレイ別設定。
macOS のみ
ちらつきの抑制と、ディスプレイ別の Night Shift / True Tone 制御。
WINDOWS のカラー調整
対応条件を満たす Windows 10 2004 および Windows 11 21H2+ で利用できます。対応状況はシステムとハードウェアによって異なります。

01 / 読書

薄い文字を濃く

  • テキストコントラストでは、コントラストの低いページ向けに 4 段階の調整ができます。
  • 読書にご利用ください。映像の暗部補正とは別の機能です。

02 / 写真 + 動画

暗部の細部を見やすく

  • 映像の暗部補正は、写真や動画の暗部を明るくして細部を見やすくします。
  • 濃い文字も薄くなるため、読書時にはオフにしてください。

03 / カラー電子ペーパー

彩度と RGB を調整

  • プリセットや直接調整で、狭い色域を補正します。
  • 対応状況は OS、GPU、ドライバー、ディスプレイの出力経路によって異なります。

04 / ディスプレイ別

パネルごとの設定を保存

  • アプリで変更したい電子ペーパーディスプレイだけを選択します。
  • ディスプレイごとにカーブを保存でき、アプリの終了時には設定を元に戻します。

03 / 必要に応じた微調整

プリセットで足りないときは
カーブを調整。

カーブを確認しながら、ニー、ガンマ、ブラックポイント、ホワイトポイントを変更できます。

名前付きプリセットを最大 5 個保存できます。設定はディスプレイごとに保存されます。

macOS 2.6

Mac にインストール

  1. DMG をダウンロードして開きます。
  2. E‑Ink Assistant を アプリケーション にドラッグします。
  3. まず一度アプリを開いてみてください。macOS にブロックされた場合は、システム設定 → プライバシーとセキュリティを開き、このまま開くを選択します。

個人開発のソフトウェアで、現在 App Store では配信していません。初回起動時には macOS に「検証できない」という警告が表示されます。コードはすべて公開されているため、利用するかどうかを決める前に確認できます。

「このまま開く」が表示されない場合

アプリを「アプリケーション」に移動した後、ターミナルを開いて次を実行します。

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"
macOS 2.6 をダウンロード ↓役に立ったら GitHub でスターを付けてください ↗

WINDOWS 1.2

Windows にインストール

  1. セットアップファイルをダウンロードして実行します。
  2. 管理者権限の確認を承認します。
  3. スタートメニューまたはシステムトレイから E‑Ink Assistant を開きます。

Windows 7 SP1 から Windows 11 までの x64 コンピューターに対応します。利用できる機能は Windows のバージョン、GPU、ドライバー、ディスプレイの接続方式によって異なります。
