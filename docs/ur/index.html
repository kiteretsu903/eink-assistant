01 / مطالعہ

مدھم متن گہرا کریں

  • متن کا کنٹراسٹ کم کنٹراسٹ والے صفحات کے لیے چار سطحیں فراہم کرتا ہے۔
  • مطالعے کے لیے استعمال کریں؛ یہ ویڈیو کی بہتری سے الگ ہے۔

02 / تصاویر + ویڈیو

تاریک تفصیلات نمایاں کریں

  • ویڈیو کی بہتری تصاویر اور ویڈیو میں سائے کی تفصیلات نمایاں کرتی ہے۔
  • مطالعے کے لیے اسے بند کریں کیونکہ یہ تاریک متن بھی ہلکا کرتی ہے۔

03 / رنگین ای اِنک

رنگوں کی سیرابی اور RGB بدلیں

  • محدود رنگی وسعت کی تلافی کے لیے پیشگی ترتیبات یا براہ راست کنٹرولز استعمال کریں۔
  • دستیابی آپریٹنگ سسٹم، GPU، ڈرائیور اور ڈسپلے کے راستے پر منحصر ہے۔

04 / ہر ڈسپلے کے لیے

ہر پینل کی ترتیبات محفوظ رکھیں

  • صرف ان ای اِنک ڈسپلے کو نشان زد کریں جنہیں ایپ سے تبدیل کرنا چاہتے ہیں۔
  • مختلف ڈسپلے کے لیے منحنیات محفوظ کریں اور ایپ بند ہونے پر اصل ترتیبات بحال کریں۔

03 / اختیاری باریک ترتیب

منحنی بدلیں
جب پیشگی ترتیبات کافی نہ ہوں۔

منحنی دیکھتے ہوئے موڑ، گاما، سیاہ نقطہ اور سفید نقطہ بدلیں۔

ناموں کے ساتھ زیادہ سے زیادہ پانچ پیشگی ترتیبات محفوظ کریں۔ ہر ڈسپلے کی ترتیبات الگ محفوظ ہوتی ہیں۔

macOS 2.6

Mac پر نصب کریں

  1. DMG ڈاؤن لوڈ کر کے کھولیں۔
  2. E‑Ink Assistant کو Applications میں کھینچیں۔
  3. ایک بار ایپ کھولنے کی کوشش کریں۔ اگر macOS روکے تو سسٹم ترتیبات → رازداری & سلامتی کھولیں اور پھر بھی کھولیں منتخب کریں۔

یہ آزادانہ طور پر تیار کردہ سافٹ ویئر ہے اور فی الحال App Store پر نہیں ہے۔ پہلی بار کھولنے پر macOS تصدیق نہ ہو سکنے کی تنبیہ دکھائے گا۔ کوڈ مکمل اوپن سورس ہے، اس لیے استعمال کا فیصلہ کرنے سے پہلے آپ اسے دیکھ سکتے ہیں۔

اگر ”پھر بھی کھولیں“ ظاہر نہ ہو

ایپ کو Applications میں منتقل کرنے کے بعد Terminal کھولیں اور چلائیں:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"
