01 / OKWENZIWA ZIZILAWULI

Khetha isilawuli
ngokomxholo.

Umahluko wombhalo wenza amaphepha okufunda abe mnyama. Ukuphucula ividiyo kubonisa iinkcukacha ezimnyama zomfanekiso. Ukutyeba kombala neRGB kunceda iiphaneli ze-e-ink ezinemibala.

Imiboniso eyimizekelo. Iziphumo ziyahluka ngokwephaneli nangomxholo wokuqala.

01 / UKUFUNDA

Yenza umbhalo ofipheleyo ube mnyama

  • Umahluko wombhalo unamanqanaba amane kumaphepha anomahluko ophantsi.
  • Wusebenzise xa ufunda; wahlukile kuKuphucula ividiyo.

02 / IIFOTO + IVIDIYO

Bonisa iinkcukacha ezimnyama

  • Ukuphucula ividiyo kuveza iinkcukacha zezithunzi kwiifoto nakwiividiyo.
  • Kucime xa ufunda kuba kukhanyisa nombhalo omnyama.

03 / I-E-INK ENEMIBALA

Lungisa ukutyeba kombala neRGB

  • Sebenzisa iisetingi ezilungiselelweyo okanye izilawuli ezithe ngqo ukubuyekeza uluhlu lwemibala oluncinci.
  • Ukufumaneka kuxhomekeke kwinkqubo yokusebenza, kwiGPU, kwidrayiva nakwindlela yokubonisa.

04 / ISIKRINI NGASINYE

Gcina iisetingi zephaneli nganye

  • Phawula kuphela izikrini ze-e-ink ofuna i-app izitshintshe.
  • Gcina amagophe ezikrini ezahlukeneyo uze ubuyisele iisetingi xa i-app iphuma.

03 / UHLENGAHLENGISO OLONGEZELELEKILEYO OLUKHETHEKAYO

Lungisa igophe
xa iisetingi ezilungiselelweyo zinganelanga.

Tshintsha indawo yokugoba, igamma, indawo emnyama nendawo emhlophe ngoxa ujonga igophe.

Gcina ukuya kutsho kwiisetingi ezilungiselelweyo ezintlanu ezinamagama. Iisetingi zigcinwa ngokwahlukeneyo kwisikrini ngasinye.

macOS 2.6

Faka kwiMac

  1. Khuphela uze uvule iDMG.
  2. Tsala E‑Ink Assistant uye kuApplications.
  3. Zama ukuvula i-app kube kanye. Ukuba imacOS iyayivimba, vula Iisetingi zenkqubo → Ubumfihlo & Nokhuseleko uze ukhethe Vula nangona kunjalo.

Le software iphuhliswe ngokuzimeleyo kwaye ayikho kwiApp Store ngoku. imacOS iza kubonisa isilumkiso sokuba ayikwazi ukuyiqinisekisa xa uyivula okokuqala. Ikhowudi ivulelekile ngokupheleleyo, ngoko ungayihlola ngaphambi kokuthatha isigqibo sokuyisebenzisa.

Ukuba “Vula nangona kunjalo” ayibonakali

Emva kokusa i-app kuApplications, vula iTerminal uze usebenzise:

xattr -dr com.apple.quarantine "/Applications/E-Ink Assistant.app"

WINDOWS 1.2

Faka kwiWindows

  1. Khuphela uze uqhube ifayile yokufaka.
  2. Vuma isicelo somlawuli.
  3. Vula iE‑Ink Assistant kwimenyu yokuqala okanye kwitreyi yenkqubo.

YeWindows 7 SP1 ukuya kwiWindows 11 kwiikhompyutha ze-x64. Izilawuli ezikhoyo zixhomekeke kwinguqulelo yeWindows, kwiGPU, kwidrayiva nakuqhagamshelo lwesikrini.
