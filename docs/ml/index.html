01 / നിയന്ത്രണങ്ങൾ ചെയ്യുന്നത്

ഉള്ളടക്കത്തിനനുസരിച്ചുള്ള
നിയന്ത്രണം തിരഞ്ഞെടുക്കുക.

ടെക്സ്റ്റ് കോൺട്രാസ്റ്റ് വായനാ പേജുകൾ ഇരുണ്ടതാക്കുന്നു. വീഡിയോ മെച്ചപ്പെടുത്തൽ ഇരുണ്ട ചിത്രങ്ങളിലെ വിശദാംശങ്ങൾ വെളിപ്പെടുത്തുന്നു. വർണ്ണസാന്ദ്രതയും RGB-യും നിറമുള്ള ഇ-ഇങ്ക് പാനലുകളെ സഹായിക്കുന്നു.

വിശദീകരണത്തിനുള്ള പ്രിവ്യൂകൾ. ഫലങ്ങൾ പാനലിനെയും ഉറവിട ഉള്ളടക്കത്തെയും ആശ്രയിക്കുന്നു.

02 / സവിശേഷതകളുടെ വിശദാംശങ്ങൾ

MAC, WINDOWS താരതമ്യം

പൊതുവായ നിയന്ത്രണങ്ങൾ.
സിസ്റ്റത്തിനനുസരിച്ചുള്ള പരിമിതികൾ.

ഓരോ ഓപ്പറേറ്റിംഗ് സിസ്റ്റത്തിലും ലഭ്യമായ പൊതു ഡിസ്പ്ലേ നിയന്ത്രണങ്ങളാണ് ആപ്പ് ഉപയോഗിക്കുന്നത്. പിന്തുണയില്ലാത്ത നിയന്ത്രണങ്ങൾ മറയ്ക്കുകയോ വിശദീകരിക്കുകയോ ചെയ്യും.

രണ്ടിലും
ടെക്സ്റ്റ് കോൺട്രാസ്റ്റ്, വീഡിയോ മെച്ചപ്പെടുത്തൽ, കർവുകൾ, പ്രീസെറ്റുകൾ, ഓരോ ഡിസ്പ്ലേയ്ക്കുമുള്ള ക്രമീകരണങ്ങൾ.
macOS-ൽ മാത്രം
മിന്നൽ കുറയ്ക്കലും ഓരോ ഡിസ്പ്ലേയ്ക്കുമുള്ള Night Shift / True Tone നിയന്ത്രണവും.
WINDOWS വർണ്ണം
ബാധകമായ Windows 10 2004, Windows 11 21H2+ സിസ്റ്റങ്ങൾ; ലഭ്യത സിസ്റ്റത്തെയും ഹാർഡ്‌വെയറിനെയും ആശ്രയിക്കുന്നു.

01 / വായന

മങ്ങിയ ടെക്സ്റ്റ് ഇരുണ്ടതാക്കുക

  • കുറഞ്ഞ കോൺട്രാസ്റ്റുള്ള പേജുകൾക്ക് ടെക്സ്റ്റ് കോൺട്രാസ്റ്റ് നാല് നിലകൾ നൽകുന്നു.
  • വായനയ്ക്ക് ഉപയോഗിക്കുക; ഇത് വീഡിയോ മെച്ചപ്പെടുത്തലിൽ നിന്ന് വേറിട്ടതാണ്.

02 / ഫോട്ടോകൾ + വീഡിയോ

ഇരുണ്ട വിശദാംശങ്ങൾ വെളിപ്പെടുത്തുക

  • വീഡിയോ മെച്ചപ്പെടുത്തൽ ഫോട്ടോകളിലെയും വീഡിയോയിലെയും നിഴൽ വിശദാംശങ്ങൾ തെളിച്ചമുള്ളതാക്കുന്നു.
  • ഇത് ഇരുണ്ട ടെക്സ്റ്റും തെളിച്ചമുള്ളതാക്കുന്നതിനാൽ വായനയ്ക്ക് ഓഫ് ചെയ്യുക.

03 / നിറമുള്ള ഇ-ഇങ്ക്

വർണ്ണസാന്ദ്രതയും RGB-യും ക്രമീകരിക്കുക

  • പരിമിതമായ വർണ്ണപരിധി പരിഹരിക്കാൻ പ്രീസെറ്റുകളോ നേരിട്ടുള്ള നിയന്ത്രണങ്ങളോ ഉപയോഗിക്കുക.
  • ലഭ്യത ഓപ്പറേറ്റിംഗ് സിസ്റ്റം, GPU, ഡ്രൈവർ, ഡിസ്പ്ലേ പാത എന്നിവയെ ആശ്രയിക്കുന്നു.

04 / ഓരോ ഡിസ്പ്ലേയ്ക്കും

ഓരോ പാനലിന്റെയും ക്രമീകരണങ്ങൾ സൂക്ഷിക്കുക

  • ആപ്പ് മാറ്റേണ്ട ഇ-ഇങ്ക് ഡിസ്പ്ലേകൾ മാത്രം അടയാളപ്പെടുത്തുക.
  • വ്യത്യസ്ത ഡിസ്പ്ലേകൾക്കായി കർവുകൾ സംരക്ഷിക്കുക; ആപ്പിൽ നിന്ന് പുറത്തുകടക്കുമ്പോൾ ക്രമീകരണങ്ങൾ പഴയപടിയാക്കുക.

03 / ഐച്ഛിക സൂക്ഷ്മ ക്രമീകരണം

പ്രീസെറ്റുകൾ മതിയാകാത്തപ്പോൾ
കർവ് ക്രമീകരിക്കുക.

കർവ് നോക്കിക്കൊണ്ട് വളവ് മാറുന്ന ബിന്ദു, ഗാമ, ബ്ലാക്ക് പോയിന്റ്, വൈറ്റ് പോയിന്റ് എന്നിവ മാറ്റുക.

പേരിട്ട അഞ്ച് പ്രീസെറ്റുകൾ വരെ സംരക്ഷിക്കുക. ഓരോ ഡിസ്പ്ലേയ്ക്കും ക്രമീകരണങ്ങൾ വേർതിരിച്ച് സൂക്ഷിക്കുന്നു.

  1. DMG ഡൗൺലോഡ് ചെയ്ത് തുറക്കുക.
  2. E‑Ink Assistant Applications ഫോൾഡറിലേക്ക് വലിച്ചിടുക.
  3. ആപ്പ് ഒരിക്കൽ തുറക്കാൻ ശ്രമിക്കുക. macOS തടഞ്ഞാൽ സിസ്റ്റം ക്രമീകരണങ്ങൾ → സ്വകാര്യത & സുരക്ഷ തുറന്ന് എന്നിരുന്നാലും തുറക്കുക തിരഞ്ഞെടുക്കുക.

ഇത് സ്വതന്ത്രമായി വികസിപ്പിച്ച സോഫ്റ്റ്‌വെയറാണ്; നിലവിൽ App Store-ൽ ഇല്ല. ആദ്യം തുറക്കുമ്പോൾ പരിശോധിക്കാൻ കഴിയുന്നില്ല എന്ന മുന്നറിയിപ്പ് macOS കാണിക്കും. കോഡ് പൂർണ്ണമായും ഓപ്പൺ സോഴ്സായതിനാൽ ഉപയോഗിക്കണോ എന്ന് തീരുമാനിക്കുന്നതിന് മുമ്പ് പരിശോധിക്കാം.

“എന്നിരുന്നാലും തുറക്കുക” കാണുന്നില്ലെങ്കിൽ

ആപ്പ് Applications-ലേക്ക് മാറ്റിയശേഷം Terminal തുറന്ന് പ്രവർത്തിപ്പിക്കുക:

WINDOWS 1.2

Windows-ൽ ഇൻസ്റ്റാൾ ചെയ്യുക

  1. Setup ഫയൽ ഡൗൺലോഡ് ചെയ്ത് പ്രവർത്തിപ്പിക്കുക.
  2. അഡ്മിനിസ്ട്രേറ്റർ അനുമതിക്കുള്ള അഭ്യർഥന അംഗീകരിക്കുക.
  3. Start മെനുവിൽ നിന്നോ സിസ്റ്റം ട്രേയിൽ നിന്നോ E‑Ink Assistant തുറക്കുക.

x64 കമ്പ്യൂട്ടറുകളിൽ Windows 7 SP1 മുതൽ Windows 11 വരെ. ലഭ്യമായ നിയന്ത്രണങ്ങൾ Windows പതിപ്പ്, GPU, ഡ്രൈവർ, ഡിസ്പ്ലേ കണക്ഷൻ എന്നിവയെ ആശ്രയിക്കുന്നു.
